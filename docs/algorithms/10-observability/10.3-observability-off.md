# 10.3 The observability-off check

Section 10, *Observability*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Observability must never change what a call does -> an all-off build produces the same media results, bit for bit

## The issue

Observability code sits next to the code that makes decisions. A switch that is supposed to remove it must not change a single decision. The only proof is to run the same scenarios in both builds and compare the media results exactly.

## Design

libwebrtc M157 counterpart: none (ours). Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.1](../../design/libwebrtc-parity.md#101-stun-messages-srcp2pstuncc-c2-986). Requirement C8. The `events` counts and the `--library` metrics exist only in the default build and are not compared.
