# 10.1 Build and runtime switches

Section 10, *Observability*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Observability costs bytes and time on small devices -> each output is compiled out by a switch and also gated at run time

## The issue

On a small device or in a library used inside a larger app, logs, counters, events and stats cost code size, CPU and memory, and an app may not want them at all. Switches at build time remove the code and switches at run time turn the outputs off, with a guarantee that neither changes what the call does.

## Design

Observability build switches and their runtime counterparts (issue #988, requirement C8).

Each observability output can be compiled out with a CMake option, and each one that is compiled in has a runtime switch:

| Output | CMake option (default) | Runtime switch | |---|---|---| | Metrics (`MetricsSource`, `MetricsRegistry`) | `SM_ENABLE_METRICS` (ON) | Computed only when the app exports them (`MetricsRegistry::Export`). Compiled out, `Histogram::Add` and `MetricsRegistry::Export` do nothing. | | Decision events (`SM_EVENT`, `EventLog`) | `SM_ENABLE_EVENTS` (ON) | The component's `EventSink*` (null: off). Compiled out, `SM_EVENT` expands to nothing, so a sink gets no events. | | Stats snapshot (`rtp::Session::GetStats`, `pc::GetConnectionStats`) | `SM_ENABLE_STATS` (ON) | Computed only when the app asks. Compiled out, both return `ObsStatus::kNotSupported`. | | Text log (`SM_LOG`, sm/core/logging.h) | `SM_LOG_MIN_LEVEL` (`VERBOSE`) | `SetLogSeverity`, default warnings. Levels below the compiled minimum are compiled out, and asking for them returns `ObsStatus::kNotSupported`. |

The rule: a runtime switch can't turn on something compiled out. The calls that would return `ObsStatus::kNotSupported` instead, with no exceptions. None of these outputs changes what the library does with media: a build with all of them off gives bit-identical media (tools/check_observability_off.py checks it on the scenario suite).

Metrics: counters, gauges and fixed-memory histograms, plus exporters.

Each algorithm keeps its own plain stats struct (cheap, always on, the equivalent of WebRTC getStats()) and implements MetricsSource so a MetricsRegistry can export everything as JSON or Prometheus text.

Structured event log for observability, the lightweight counterpart of the WebRTC RTC event log. Algorithms emit decision events (NACK sent, overuse detected, keyframe requested, target rate changed) through an optional EventSink pointer in their config. A null sink costs one branch; building with SM_ENABLE_EVENTS=0 removes the calls entirely.

Minimal text logging in the spirit of libwebrtc's RTC_LOG (rtc_base/logging.h, not in compare/webrtc/reference/): severities LS_VERBOSE, LS_INFO, LS_WARNING, LS_ERROR and LS_NONE, a process-wide minimum severity, and a sink. Issue #988 (requirement C8).

```
  SM_LOG(kWarning, "unroutable datagram, ssrc %u", ssrc);
```

- Compile time: `SM_LOG_MIN_LEVEL` (CMake `SM_LOG_MIN_LEVEL`, VERBOSE by

```
  default) removes every call below that severity; NONE removes them all.
```

- Run time: `SetLogSeverity` (warnings by default). A severity below the

```
  compiled minimum returns ObsStatus::kNotSupported and changes nothing.
```

- Output: stderr unless the app sets a sink (`SetLogSink`), for example to

```
  forward to os_log or the browser console. The library reads no clock, so a
  message carries no time; the sink can add one.
```

Logging never changes what the library does. Set the severity and the sink before other threads log; logging itself only reads them.

libwebrtc M157 counterpart: none: libwebrtc has `RTC_LOG` and `RTC_HISTOGRAM`, always compiled in, with no switch to build them out. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.1](../../design/libwebrtc-parity.md#101-stun-messages-srcp2pstuncc-c2-986). Requirement C8. Beyond libwebrtc by design; parity 10.1 lists the histograms libwebrtc records that we do not.

```cpp
#define SM_ENABLE_STATS 1

// 0 verbose, 1 info, 2 warning, 3 error, 4 none (sm::LogSeverity).
#ifndef SM_LOG_MIN_LEVEL
#define SM_LOG_MIN_LEVEL 0
#endif

namespace sm {

enum class ObsStatus : uint8_t {
  kOk,
  kNotSupported,  // Compiled out in this build.
};

// What this build compiled in.
struct ObservabilityBuild {
  bool metrics = false;
  bool events = false;
  bool stats = false;
  int log_min_level = 4;  // sm::LogSeverity as an int; 4 (none): no text log.
};

constexpr ObservabilityBuild CompiledObservability() {
  ObservabilityBuild b;
#if SM_ENABLE_METRICS
  b.metrics = true;
#endif
#if SM_ENABLE_EVENTS
  b.events = true;
#endif
#if SM_ENABLE_STATS
  b.stats = true;
#endif
  b.log_min_level = SM_LOG_MIN_LEVEL;
  return b;
}

}  // namespace sm
```

```cpp
namespace sm {

// Log-linear histogram over non-negative values with a fixed 660-byte
// footprint. Four sub-buckets per octave from 2^-10 to 2^30 gives about
// +-9% relative error on percentiles; exact min, max, mean and count.
class Histogram {
 public:
  static constexpr int kSubBuckets = 4;
  static constexpr int kMinExp = -10;
  static constexpr int kMaxExp = 30;
  static constexpr int kNumBuckets = 1 + (kMaxExp - kMinExp + 1) * kSubBuckets;

  void Add(double v);
  void Reset();
  void Merge(const Histogram& o);

  uint64_t count() const { return count_; }
  double sum() const { return sum_; }
  double min() const { return count_ ? min_ : 0.0; }
  double max() const { return count_ ? max_ : 0.0; }
  double mean() const { return count_ ? sum_ / static_cast<double>(count_) : 0.0; }
  // p in [0, 100].
  double Percentile(double p) const;

};

class MetricsWriter {
 public:
  virtual ~MetricsWriter() = default;
  virtual void Counter(std::string_view name, uint64_t value) = 0;
  virtual void Gauge(std::string_view name, double value) = 0;
  virtual void Hist(std::string_view name, const Histogram& h) = 0;
};

class MetricsSource {
 public:
  virtual ~MetricsSource() = default;
  virtual void ExportMetrics(MetricsWriter& w) const = 0;
};

// Flat name -> value map. Histograms expand to .count/.mean/.p50/.p95/.p99/.max.
// Used by tests, benchmarks and the JSON exporter.
class MapMetricsWriter : public MetricsWriter {
 public:
  void Counter(std::string_view name, uint64_t value) override;
  void Gauge(std::string_view name, double value) override;
  void Hist(std::string_view name, const Histogram& h) override;
  const std::map<std::string, double>& values() const { return values_; }
  double Get(const std::string& name, double fallback = -1) const;
  std::string ToJson() const;

};

// Prometheus text exposition format (counters, gauges, summaries).
class PrometheusMetricsWriter : public MetricsWriter {
 public:
  void Counter(std::string_view name, uint64_t value) override;
  void Gauge(std::string_view name, double value) override;
  void Hist(std::string_view name, const Histogram& h) override;
  const std::string& text() const { return text_; }

};

// Holds non-owning pointers to sources under a name prefix
// (e.g. "video.nack"). Not thread-safe: export from the thread that owns the
// sources, or snapshot under the caller's lock.
class MetricsRegistry {
 public:
  void Register(std::string prefix, const MetricsSource* source);
  void Unregister(const MetricsSource* source);
  void Export(MetricsWriter& w) const;
  std::string ToJson() const;
  std::string ToPrometheus() const;
  size_t size() const { return sources_.size(); }

};

// Convenience: export a single source into a map (tests / benchmarks).
std::map<std::string, double> CollectMetrics(const MetricsSource& s);

}  // namespace sm
```

```cpp
namespace sm {

struct Event {
  Timestamp time;
  const char* module = "";  // Static string, e.g. "nack".
  const char* name = "";    // Static string, e.g. "request".
  double value = 0;
  int64_t aux = 0;
};

class EventSink {
 public:
  virtual ~EventSink() = default;
  virtual void OnEvent(const Event& e) = 0;
};

// Fixed-capacity ring buffer of events with JSON-lines export and an optional
// forwarding callback (e.g. to platform logging such as os_log or logcat).
class EventLog : public EventSink {
 public:
  explicit EventLog(size_t capacity = 4096);
  void OnEvent(const Event& e) override;
  void SetCallback(std::function<void(const Event&)> cb) { callback_ = std::move(cb); }

  size_t size() const { return count_ < capacity_ ? count_ : capacity_; }
  uint64_t total() const { return count_; }
  // Oldest to newest.
  std::vector<Event> Snapshot() const;
  size_t Count(const char* module, const char* name) const;
  std::string ToJsonLines() const;
  void Clear();

};

}  // namespace sm

#if SM_ENABLE_EVENTS
#define SM_EVENT(sink, t, module, name, value, aux)                     \

                                          static_cast<int64_t>(aux)});  \
  } while (0)
#else
#define SM_EVENT(sink, t, module, name, value, aux) \

  } while (0)
#endif
```

```cpp
namespace sm {

enum class LogSeverity : int {
  kVerbose = 0,
  kInfo = 1,
  kWarning = 2,
  kError = 3,
  kNone = 4,
};

inline constexpr LogSeverity kCompiledMinLogSeverity = static_cast<LogSeverity>(SM_LOG_MIN_LEVEL);
// The runtime default: warnings and errors.
inline constexpr LogSeverity kDefaultLogSeverity = LogSeverity::kWarning;

// Whether a call at this severity is compiled in.
constexpr bool LogCompiled(LogSeverity s) {
  return s != LogSeverity::kNone && static_cast<int>(s) >= SM_LOG_MIN_LEVEL;
}

struct LogMessage {
  LogSeverity severity = LogSeverity::kInfo;
  const char* file = "";  // __FILE__ of the call.
  int line = 0;
  const char* text = "";  // Formatted, without a trailing newline.
};
using LogSink = std::function<void(const LogMessage&)>;

// Messages at `min` and above are logged. kNone turns logging off. A severity
// that is compiled out returns kNotSupported and leaves the setting unchanged.
ObsStatus SetLogSeverity(LogSeverity min);
LogSeverity GetLogSeverity();
// Null restores the stderr sink.
void SetLogSink(LogSink sink);
// Whether a message at `s` would be logged now.
bool LogEnabled(LogSeverity s);
// The SM_LOG back end: printf-style; messages longer than 1 KB are truncated.
void LogPrintf(LogSeverity s, const char* file, int line, const char* fmt, ...)
#if defined(__GNUC__) || defined(__clang__)
    __attribute__((format(printf, 4, 5)))
#endif
    ;

}  // namespace sm

#define SM_LOG(sev, ...)                                                                    \
  do {                                                                                      \
    if constexpr (::sm::LogCompiled(::sm::LogSeverity::sev)) {                              \
      if (::sm::LogEnabled(::sm::LogSeverity::sev))                                         \
        ::sm::LogPrintf(::sm::LogSeverity::sev, __FILE__, __LINE__, __VA_ARGS__);           \
    }                                                                                       \
  } while (0)
```

## Metrics and observability

Every class implements `MetricsSource::ExportMetrics`, so it can be registered in a `MetricsRegistry` and exported as JSON or Prometheus text. Histograms expand to `.count/.mean/.p50/.p95/.p99/.max`.
