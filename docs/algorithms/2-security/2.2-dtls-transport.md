# 2.2 DTLS transport

Section 2, *Security*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- A secure channel over unreliable ICE packets -> DTLS handshake, role from SDP `a=setup`, the peer's certificate checked against the SDP fingerprint

## The issue

ICE delivers unreliable datagrams, and DTLS needs a handshake of several flights, retransmission, and record handling over them. It must also decide client or server from SDP, check the peer's certificate against the fingerprint from signalling and tell DTLS packets from STUN and RTP on one port.

## Design

DTLS for WebRTC: libwebrtc's rtc_base/openssl_stream_adapter.cc in DTLS mode (M157), ported for milestone 3 (#984 part 2). It runs the handshake over datagrams the caller moves (from ICE, or the test bench's emulated link), checks the peer's certificate against the fingerprint from SDP, negotiates DTLS-SRTP (RFC 5764) and exports the SRTP keys. Time is the caller's: BoringSSL's clock is set from it (SSL_CTX_set_current_time_cb), and mbedTLS's DTLS timer callbacks read it (#998), so runs are deterministic on a simulated clock.

DTLS over an ICE transport: libwebrtc's p2p/dtls/dtls_transport.{h,cc} and dtls_transport_internal.h at M157 (compare/webrtc/reference/), ported for DTLS-SRTP (C5 part 2, #1006) on sm::tls::DtlsTransport (#994), which plays libwebrtc's SSLStreamAdapter.

What it does, as libwebrtc does: - Packets from ICE are demultiplexed by their first byte (RFC 7983): DTLS records go to the DTLS stack, and once

```
  connected, RTP/RTCP (SRTP) passes up untouched, marked kSrtpEncrypted (SRTP bypass). STUN is ICE's own.
```

- The DTLS role comes from SDP's a=setup (NegotiateDtlsRole, pc/jsep_transport.cc), or, if a ClientHello arrives

```
  first, this end becomes the server. ClientHellos that arrive before DTLS starts are stashed (up to 4) and fed in
  when it does.
```

- The remote fingerprint from SDP is checked against the peer's certificate; a mismatch fails the transport (and

```
  the peer, through a fatal alert). A fingerprint that arrives after the handshake is checked then.
```

- The handshake starts when ICE first becomes writable, with the first retransmission timeout 2 x the ICE RTT

```
  clamped to 50-3000 ms (ComputeRetransmissionTimeout), or the DTLS stack's 50 ms without an RTT estimate.
```

- SendPacket encrypts with DTLS, or with kPfSrtpBypass sends an RTP/RTCP packet (already SRTP) directly. - Without a local certificate it is a passthrough (IsDtlsActive() false), as in libwebrtc.

The library's time model: nothing reads a clock or starts a thread. Calls that can send take `now`, and the handshake's retransmission timer is NextTimeout()/OnTimeout(now), which the owner runs.

Differences from libwebrtc, none of them on the wire: - DTLS-in-STUN (dtls_stun_piggyback_controller, SPED) is not ported: M157 has it behind a field trial that is off

```
  by default (#1006).
```

- The negotiated key-exchange group and peer signature algorithm (GetSslGroupId, GetSslPeerSignatureAlgorithm)

```
  are not exposed: sm::tls::DtlsTransport doesn't report them. The cipher suite is (GetSslCipherSuite and
  GetTlsCipherSuiteName, for the connection stats, #1059).
```

- No UMA histograms, RTC event log entries or network route (PacketTransportInternal's comment).

DTLS packet classification and the packet stash: libwebrtc's p2p/dtls/dtls_utils.{h,cc} at M157 (compare/webrtc/reference/), for the DTLS transport (#1006). DTLS records share the ICE transport with STUN and SRTP; RFC 7983 tells them apart by the first byte (DTLS is 20-63).

libwebrtc M157 counterpart: `rtc_base/openssl_stream_adapter.{h,cc}` (the DTLS part), `p2p/dtls/dtls_transport.{h,cc}`, `p2p/dtls/dtls_utils.{h,cc}`. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.2](../../design/libwebrtc-parity.md#102-tls-backend-mbed-tls-srctlsmbedtls_cc-c1-part-3-998), [10.7](../../design/libwebrtc-parity.md#107-srtp-and-dtls-srtp-transports-srcpcrtp_transportsrtp_transportdtls_srtp_transportcc-c5-part-3-1007). Requirements C1 and C5. `p2p::DtlsTransport` sits over an ICE transport; `tls::DtlsTransport` is the backend's record layer.

```cpp
namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

// SRTP protection profiles (RFC 5764, RFC 7714 ids; ssl_stream_adapter.h).
inline constexpr int kSrtpAes128CmSha1_80 = 0x0001;
inline constexpr int kSrtpAes128CmSha1_32 = 0x0002;
inline constexpr int kSrtpAeadAes128Gcm = 0x0007;
inline constexpr int kSrtpAeadAes256Gcm = 0x0008;

// DTLS versions on the wire (ssl_stream_adapter.h kDtls12VersionBytes / kDtls13VersionBytes).
inline constexpr int kDtls12 = 0xfefd;
inline constexpr int kDtls13 = 0xfefc;

// TLS named groups (IANA; BoringSSL's SSL_GROUP_*).
inline constexpr uint16_t kSslGroupSecp256r1 = 23;
inline constexpr uint16_t kSslGroupSecp384r1 = 24;
inline constexpr uint16_t kSslGroupX25519 = 29;

enum class DtlsRole { kClient, kServer };
enum class DtlsState { kNew, kConnecting, kConnected, kFailed, kClosed };

struct DtlsConfig {
  // CryptoOptions::GetSupportedDtlsSrtpCryptoSuites with M157's defaults: AES-128-CM-SHA1-80, then GCM (enabled,
  // not preferred).
  std::vector<int> srtp_crypto_suites = {kSrtpAes128CmSha1_80, kSrtpAeadAes256Gcm, kSrtpAeadAes128Gcm};
  // The highest version offered: DTLS 1.3 when the backend has it (GetMaxVersion with SSL_PROTOCOL_NOT_GIVEN),
  // DTLS 1.2 to cap it. The lowest is always DTLS 1.2.
  int max_version = kDtls13;
  // The ephemeral key-exchange groups (CryptoOptions::ephemeral_key_exchange_cipher_groups, set with
  // SSL_set1_group_ids): GetDefaultEphemeralKeyExchangeCipherGroups without the WebRTC-EnableDtlsPqc trial, X25519,
  // P-256, P-384 (TLS group ids). Without it BoringSSL's own default answers a DTLS 1.3 ClientHello with a
  // HelloRetryRequest, an extra round trip libwebrtc doesn't have (#1006).
  std::vector<uint16_t> ssl_group_ids = {kSslGroupX25519, kSslGroupSecp256r1, kSslGroupSecp384r1};
  int mtu = 1200;                     // dtls_mtu_
  int initial_timeout_ms = 50;        // dtls_handshake_timeout_ms_
};

class DtlsTransport {
 public:
  DtlsTransport(std::unique_ptr<SslIdentity> identity, DtlsRole role, DtlsConfig config = {});
  ~DtlsTransport();
  DtlsTransport(const DtlsTransport&) = delete;
  DtlsTransport& operator=(const DtlsTransport&) = delete;

  // The peer's fingerprint, from SDP. A certificate already received is checked now (SetPeerCertificateDigest); one
  // that arrives later is checked when it does. False if the check fails (the transport then fails).
  bool SetPeerFingerprint(const SslFingerprint& fingerprint, Timestamp now);

  // Starts the handshake: the client sends its first flight. False if the backend could not be set up.
  bool Start(Timestamp now);
  // A datagram from the peer (handshake or application data).
  void OnPacket(std::span<const uint8_t> datagram, Timestamp now);
  // The first handshake retransmission timeout (SetInitialRetransmissionTimeout): the DTLS transport sets it from
  // the ICE RTT before Start (#1006). Later calls change the next handshake's.
  void SetInitialRetransmissionTimeout(int timeout_ms);
  // When the retransmission timer fires, if one is running, and its handler. It runs while connecting, and after the
  // handshake while the last flight waits for an ACK (DTLS 1.3).
  std::optional<Timestamp> NextTimeout() const;
  void OnTimeout(Timestamp now);

  // Datagrams to send to the peer, oldest first.
  std::vector<std::vector<uint8_t>> TakeOutgoing();
  // Application data (for SCTP, C7): false before the handshake completes.
  bool Send(std::span<const uint8_t> data, Timestamp now);
  std::vector<std::vector<uint8_t>> TakeReceived();

  DtlsState state() const { return state_; }
  // The handshake finished (IsTlsConnected), even if the peer's certificate waits for its fingerprint.
  bool handshake_complete() const;
  DtlsRole role() const { return role_; }
  // The negotiated version (kDtls12 or kDtls13), or 0 before the handshake completes.
  int version() const;
  // The negotiated SRTP profile, or 0.
  int srtp_crypto_suite() const;
  // The negotiated TLS cipher suite: its IANA id (GetSslCipherSuite) and standard name, such as
  // "TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256" (GetTlsCipherSuiteName); 0 and empty before the handshake completes.
  int ssl_cipher_suite() const;
  std::string ssl_cipher_suite_name() const;
  // RFC 5764 4.2: the "EXTRACTOR-dtls_srtp" keying material (client key, server key, client salt, server salt).
  bool ExportSrtpKeyingMaterial(std::span<uint8_t> out) const;
  // The peer's certificate, once received.
  const SslCertificate* peer_certificate() const { return peer_cert_ ? &*peer_cert_ : nullptr; }
  int retransmissions() const { return retransmissions_; }

  // Backend plumbing (the BIO and the callbacks); not for callers.
  struct Impl;

};

// The SRTP key and salt lengths of a profile, in bytes (SrtpCryptoSuiteToKeyAndSaltLength); false if unknown.
bool SrtpKeyAndSaltLength(int crypto_suite, int& key_len, int& salt_len);

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls
```

```cpp
namespace sm::p2p {

// api/dtls_transport_interface.h.
enum class DtlsTransportState { kNew, kConnecting, kConnected, kClosed, kFailed };
using SslRole = tls::DtlsRole;

// ConnectionRole (SDP's a=setup, RFC 4145) and SdpType are in sm/p2p/transport_description.h (#1062).

// JsepTransport::NegotiateDtlsRole: this end's DTLS role from the local description's type and both a=setup values
// (RFC 5763 section 5, RFC 8842 section 5.3). `current_role` is the role already negotiated, if any. Returns false
// (and leaves `role` alone) for a combination libwebrtc rejects.
bool NegotiateDtlsRole(SdpType local_description_type, ConnectionRole local_connection_role,
                       ConnectionRole remote_connection_role, std::optional<SslRole> current_role,
                       std::optional<SslRole>& role);

// libwebrtc's DtlsTransportInternalImpl.
class DtlsTransport : public PacketTransportInternal {
 public:
  using DtlsStateCallback = std::function<void(DtlsTransport*, DtlsTransportState)>;
  using RoleCallback = std::function<void(DtlsTransport*, SslRole)>;

  // See RFC 9147 section 5.8.2: 400 ms first timeout, as 2 x this estimate.
  static constexpr int kDefaultHandshakeEstimateRttMs = 200;

  // `ice_transport` must outlive this transport. `srtp_crypto_suites` are the DTLS-SRTP profiles offered
  // (CryptoOptions::GetSupportedDtlsSrtpCryptoSuites; empty for no DTLS-SRTP), and `max_version` the highest DTLS
  // version (SSL_PROTOCOL_DTLS_12 by default, as DtlsTransportInternalImpl's constructor).
  explicit DtlsTransport(IceTransportInternal* ice_transport,
                         std::vector<int> srtp_crypto_suites = tls::DtlsConfig{}.srtp_crypto_suites,
                         int max_version = tls::kDtls12);
  ~DtlsTransport() override;

  DtlsTransportState dtls_state() const { return dtls_state_; }
  const std::string& transport_name() const override { return ice_transport_->transport_name(); }
  int component() const { return ice_transport_->component(); }
  IceTransportInternal* ice_transport() { return ice_transport_; }

  // DTLS is active once a local certificate is set; otherwise packets pass straight through to ICE.
  bool IsDtlsActive() const { return dtls_active_; }
  // Makes DTLS active. Must come before SetRemoteParameters. Setting the same identity again is a no-op; changing
  // it once active fails.
  bool SetLocalCertificate(std::shared_ptr<const tls::SslIdentity> identity);
  const tls::SslIdentity* local_certificate() const { return local_certificate_.get(); }

  // The remote fingerprint (from SDP a=fingerprint) and the DTLS role (from a=setup, NegotiateDtlsRole). The role
  // is set before the fingerprint, which starts DTLS setup. An empty `digest_alg` means the peer doesn't do DTLS
  // (passthrough). A new fingerprint after DTLS was set up restarts DTLS. False for invalid parameters; a well-formed
  // fingerprint that doesn't match the peer's certificate fails the transport but returns true, as libwebrtc.
  bool SetRemoteParameters(std::string_view digest_alg, std::span<const uint8_t> digest,
                           std::optional<SslRole> role, Timestamp now);

  bool GetDtlsRole(SslRole* role) const;
  // False if the role would change after DTLS was set up.
  bool SetDtlsRole(SslRole role);

  // SendPacket, through DTLS, or with kPfSrtpBypass directly (RTP/RTCP only). -1 until connected.
  int SendPacket(Timestamp now, std::span<const uint8_t> data, const PacketOptions& options,
                 int flags = kPfNormal) override;
  bool writable() const override { return writable_; }
  bool receiving() const override { return receiving_; }
  int GetError() override { return ice_transport_->GetError(); }
  int SetOption(SocketOption opt, int value) override { return ice_transport_->SetOption(opt, value); }
  bool GetOption(SocketOption opt, int* value) override { return ice_transport_->GetOption(opt, value); }

  // The negotiated DTLS version (tls::kDtls12 or kDtls13) and DTLS-SRTP profile; false unless connected.
  bool GetSslVersionBytes(int* version) const;
  bool GetSrtpCryptoSuite(int* cipher) const;
  // The negotiated TLS cipher suite's IANA id and standard name; false (nullopt) unless connected.
  bool GetSslCipherSuite(int* cipher_suite) const;
  std::optional<std::string> GetTlsCipherSuiteName() const;
  // The peer's certificate, once the handshake received it (GetRemoteSSLCertChain).
  const tls::SslCertificate* GetRemoteCertificate() const;
  // Appends the RFC 5764 keying material for the negotiated profile (AppendSrtpKeyingMaterial): client key, server
  // key, client salt, server salt. False unless DTLS is set up and connected with a profile.
  bool AppendSrtpKeyingMaterial(std::vector<uint8_t>& keying_material) const;

  // The handshake finished; true even before the remote fingerprint verified the peer (IsDtlsConnected).
  bool IsDtlsConnected() const;
  // Handshake retransmissions so far (GetRetransmissionCount).
  int GetRetransmissionCount() const;
  // The handshake's retransmission timer: when it fires, and its handler.
  std::optional<Timestamp> NextTimeout() const;
  void OnTimeout(Timestamp now);

  // DtlsTransportInternal's signals: the DTLS state (any number of receivers), the role change (one).
  void SubscribeDtlsTransportState(const void* tag, DtlsStateCallback cb) { dtls_state_cbs_.Add(tag, std::move(cb)); }
  void UnsubscribeDtlsTransportState(const void* tag) { dtls_state_cbs_.Remove(tag); }
  void SubscribeDtlsRoleChange(RoleCallback cb) { role_change_cb_ = std::move(cb); }

  std::string ToString() const;

  // Over an ICE-lite agent (sm/p2p/ice_lite_agent.h), which has no RTT estimate: the handshake's first
  // retransmission timeout comes from kDefaultHandshakeEstimateRttMs (libwebrtc's SetFakeIceLite, set by
  // p2p/dtls/dtls_ice_integration_fixture.h on the lite side). Call it before the handshake is set up.
  void SetFakeIceLite() { fake_ice_lite_ = true; }

};

}  // namespace sm::p2p
```
