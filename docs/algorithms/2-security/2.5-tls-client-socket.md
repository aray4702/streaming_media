# 2.5 TLS client socket over TCP

Section 2, *Security*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- TURN on port 443 and other TLS-wrapped streams -> a TLS client over a TCP packet socket

## The issue

TURN on port 443 and other TLS-wrapped streams require a TLS client on a TCP connection, with certificate or fingerprint checks and a stream interface that ICE code can use like a socket. The state machine has to cope with partial reads, handshake in progress and closing.

## Design

TLS over a byte stream (issue #1035, C4 part 3, milestone 3): the TLS engine of libwebrtc's rtc_base/openssl_adapter.{h,cc} at M157 (compare/webrtc/reference/), on both sm::tls backends (BoringSSL, as libwebrtc builds, and Mbed TLS, C1). TURN over TLS (C4 part 4, #1036) runs it through sm::p2p's SslAdapter (sm/p2p/ssl_adapter.h), which moves the bytes between it and a TCP socket.

As DtlsTransport does for datagrams, the caller moves the bytes: Feed() what arrived from the peer, TakeOutgoing() what to send. Nothing here reads the caller's clock or starts a thread. Certificate validity is checked against the wall clock, as libwebrtc's X509 verification does.

What it does as OpenSSLAdapter (BeginSSL, ContinueSSL, SSLPostConnectionCheck, CreateContext): - TLS 1.2 to 1.3 (TLS_method's range in M157's BoringSSL); `max_version` caps it at 1.2 for tests. - The cipher list "ALL:!SHA256:!SHA384:!aPSK:!ECDSA+SHA1:!ADH:!LOW:!EXP:!MD5:!3DES", verify depth 4,

```
  SSL_VERIFY_PEER on both roles, OCSP stapling and SCT requested, extensions permuted (BoringSSL).
```

- SNI set to `server_name` when it isn't empty; ALPN (TransformAlpnProtocols) and the curves list

```
  (SSL_set1_curves_list, joined with ':') passed through.
```

- The peer's chain is checked against the trusted roots (SSLVerifyCallback); a chain that fails is accepted if the

```
  custom verifier (SSLCertificateVerifier::VerifyChain) accepts it, or if `ignore_bad_cert` is set
  (TLS_CERT_POLICY_INSECURE_NO_CHECK, OPT_TLS_INSECURE). Otherwise the handshake fails.
```

- After the handshake, the post-connection check: the leaf must match `server_name` (X509_check_host, so an empty

```
  name never matches) and the chain must have verified; `ignore_bad_cert` overrides a failure.
```

Differences from libwebrtc, none behavioural on the wire: - Trusted roots: libwebrtc loads its built-in root list (rtc_base/ssl_roots.h, not in the reference tree); here the

```
  caller gives roots (`trusted_roots`), and `load_system_roots` adds the platform's store where the backend finds
  one (BoringSSL's default verify paths; on Mbed TLS the usual CA bundle files). libwebrtc fails the context when no
  root loads; here a context without roots still connects under `ignore_bad_cert` or a custom verifier.
```

- No session cache (OpenSSLAdapterFactory / OpenSSLSessionCache): the TURN client creates its adapters with

```
  SSLAdapter::Create, which runs without one, so IsResumedSession is always false there too.
```

- Mbed TLS 3.6: OCSP stapling and SCT are not requested (it has neither), extensions are not permuted, and its

```
  suites are the ECDHE ones of libwebrtc's list (as its DtlsTransport, tools/catalog.py, #998).
```

The TLS client socket TURN over TLS stands on (issue #1035, C4 part 3, milestone 3).

libwebrtc's rtc_base/ssl_adapter.h at M157 (compare/webrtc/reference/): `SSLAdapter`, a Socket that wraps a stream socket and runs TLS over it, created by `SSLAdapter::Create` and configured before `StartSSL`; and the `SSLCertificateVerifier` hook (rtc_base/ssl_certificate.h) that PacketSocketTcpOptions carries. sm::p2p has no TLS library, so `Create` uses the implementation installed with SetSslAdapterFactory; sm::p2p_tls installs the one on sm::tls with InstallSslAdapterFromTls() (sm/p2p/ssl_adapter_tls.h), as InstallStunCryptoFromTls() does for STUN's crypto. Without one, Create returns nullptr, and BasicPacketSocketFactory's TLS sockets fail as libwebrtc's do when SSLAdapter::Create fails.

SslAdapter on sm::tls (issue #1035, C4 part 3): libwebrtc's rtc_base/openssl_adapter.{h,cc} at M157, the adapter half: the state machine (SSL_NONE, SSL_WAIT, SSL_CONNECTING, SSL_CONNECTED, SSL_ERROR), Send and Recv over the TLS connection, and the socket events it passes up. The TLS engine is sm::tls::TlsStream (sm/tls/tls_stream.h), on BoringSSL or Mbed TLS. In the sm::p2p_tls library, built when SM_WITH_TLS is on.

OpenSSLAdapter's BIO reads and writes the wrapped socket directly; here the adapter moves the bytes. The wrapped socket's bytes are drained into the engine on each read event and on Recv, and the engine's output goes to the socket at once, the rest waiting for its write event. That keeps libwebrtc's behaviour at the interface: - Send before the handshake completes fails with ENOTCONN. Once connected it takes the whole buffer; if the

```
  socket could not take all of the encrypted record, the rest waits (pending_data_), and the next Send fails
  with EWOULDBLOCK until a write event has flushed it.
```

- Recv fails with EWOULDBLOCK when no whole record is buffered, and when the peer sent close_notify. - The connect event goes up when the handshake and the post-connection check pass; a failure raises the close

```
  event with the error (Error("ContinueSSL", err)).
```

One addition: the adapter pulls everything the socket has into the engine, so bytes that would still sit in the socket's buffer under libwebrtc's BIO (which reads one record at a time) sit here instead. A socket signals a read again while bytes are buffered (VirtualSocket::RecvFrom's PostSignalReadEvent, "to behave like a real socket"), so the adapter signals a read again while it holds decrypted data the reader left, including data that came in the same flight as the handshake's end (announced after the connect event).

libwebrtc M157 counterpart: `rtc_base/{ssl_adapter,openssl_adapter,ssl_stream_adapter}.{h,cc}`. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.13](../../design/libwebrtc-parity.md#1013-tls-client-socket-over-tcp-srctlsboringsslmbedtls_tlscc-srcp2pssl_adapter_tlscc-c4-part-3-1035). Requirement C4 part 3, on both backends.

## Implementation skeleton

Files: [include/sm/tls/tls_stream.h](../../../include/sm/tls/tls_stream.h), [include/sm/p2p/ssl_adapter.h](../../../include/sm/p2p/ssl_adapter.h), [include/sm/p2p/ssl_adapter_tls.h](../../../include/sm/p2p/ssl_adapter_tls.h), [src/p2p/ssl_adapter_tls.cc](../../../src/p2p/ssl_adapter_tls.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

// TLS versions on the wire.
inline constexpr int kTls12 = 0x0303;
inline constexpr int kTls13 = 0x0304;

enum class TlsRole { kClient, kServer };
enum class TlsState { kNew, kConnecting, kConnected, kFailed, kClosed };

// Results of Read and Write besides a byte count.
inline constexpr int kTlsWouldBlock = -1;  // Nothing to read yet, or not connected.
inline constexpr int kTlsError = -2;       // The connection failed (state() says so).

struct TlsConfig {
  TlsRole role = TlsRole::kClient;
  // SNI and the name the server's certificate must match (ssl_host_name_, from StartSSL).
  std::string server_name;
  std::vector<std::string> alpn_protocols;
  std::vector<std::string> elliptic_curves;
  // Certificates the peer's chain may end at, DER.
  std::vector<std::vector<uint8_t>> trusted_roots;
  bool load_system_roots = true;
  // SetIgnoreBadCert: accept any certificate (TLS_CERT_POLICY_INSECURE_NO_CHECK).
  bool ignore_bad_cert = false;
  // SSLCertificateVerifier::VerifyChain, leaf first (DER): asked only when the chain fails against the roots.
  std::function<bool(const std::vector<std::vector<uint8_t>>& chain)> cert_verifier;
  // The highest version offered (kTls13, or kTls12 to cap it). The lowest is TLS 1.2.
  int max_version = kTls13;
};

class TlsStream {
 public:
  // `identity` is the certificate this end presents (SetIdentity); a server needs one, a client may have none.
  TlsStream(TlsConfig config, std::unique_ptr<SslIdentity> identity = nullptr);
  ~TlsStream();
  TlsStream(const TlsStream&) = delete;
  TlsStream& operator=(const TlsStream&) = delete;

  // BeginSSL: sets up the context and the connection and runs the first handshake step (a client's ClientHello).
  // False if it could not be set up, or the handshake failed at once.
  bool Start();
  // Bytes from the peer; the handshake advances. Application data waits for Read.
  void Feed(std::span<const uint8_t> data);
  // Bytes to send to the peer, oldest first.
  std::vector<uint8_t> TakeOutgoing();
  bool HasOutgoing() const;

  // SSL_write: the bytes taken (all of `data` once connected), kTlsWouldBlock before the handshake completes, or
  // kTlsError.
  int Write(std::span<const uint8_t> data);
  // SSL_read: the bytes read, 0 when the peer closed (close_notify), kTlsWouldBlock when no whole record is
  // buffered, or kTlsError.
  int Read(std::span<uint8_t> buffer);

  TlsState state() const { return state_; }
  // The negotiated version (kTls12 or kTls13), or 0 before the handshake completes.
  int version() const;
  // The negotiated ALPN protocol, empty if none.
  std::string alpn_protocol() const;
  // The server name the client sent (SNI), on a server; empty if none.
  std::string received_server_name() const;
  // The peer's chain verified against the roots or the custom verifier.
  bool peer_verified() const { return chain_verified_ || custom_verified_; }
  // Why the connection failed, for logs; empty otherwise.
  const std::string& error() const { return error_; }

  // Backend plumbing; not for callers.
  struct Impl;

};

// TransformAlpnProtocols: each protocol prefixed with its length; empty if one is empty or longer than 255.
std::string TransformAlpnProtocols(const std::vector<std::string>& protocols);

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls
```

```cpp
namespace sm::p2p {

// SSLCertificateVerifier: decides on a chain that failed against the trusted roots.
class SslCertificateVerifier {
 public:
  virtual ~SslCertificateVerifier() = default;
  // The peer's chain, leaf first, each certificate DER. True to accept it.
  virtual bool VerifyChain(const std::vector<std::vector<uint8_t>>& chain) = 0;
};

// SSLRole.
enum class SslRole { kClient, kServer };

class SslAdapter : public Socket {
 public:
  // For tests only, as libwebrtc says: accept any certificate (OPT_TLS_INSECURE, TLS_CERT_POLICY_INSECURE_NO_CHECK).
  virtual void SetIgnoreBadCert(bool ignore) = 0;
  virtual void SetAlpnProtocols(const std::vector<std::string>& protocols) = 0;
  virtual void SetEllipticCurves(const std::vector<std::string>& curves) = 0;
  // Not owned; must outlive the adapter.
  virtual void SetCertVerifier(SslCertificateVerifier* verifier) = 0;
  virtual void SetRole(SslRole role) = 0;
  // Roots the server's chain may end at (DER), besides the system's. libwebrtc builds its roots in
  // (rtc_base/ssl_roots.h); the library takes them from the caller.
  virtual void AddTrustedRoot(std::vector<uint8_t> der) = 0;
  // Returns 0 on success. Called while the socket is closed or connecting, the handshake starts once it connects.
  // `hostname` is the SNI and the name the certificate must match.
  virtual int StartSSL(std::string_view hostname) = 0;
  // Always false: no session cache (see sm/tls/tls_stream.h).
  virtual bool IsResumedSession() = 0;

  // SSLAdapter::Create: wraps `socket`, or returns nullptr (and drops `socket`) when no implementation is installed
  // or it can't be created.
  static std::unique_ptr<SslAdapter> Create(std::unique_ptr<Socket> socket);

  // Not supported (RTC_CHECK(false) in libwebrtc); fail with EINVAL here.
  int Listen(int) override {
    SetError(kSocketEInval);
    return -1;
  }
  std::unique_ptr<Socket> Accept(Timestamp, SocketAddress*) override {
    SetError(kSocketEInval);
    return nullptr;
  }
};

// What SslAdapter::Create calls. Install once at startup, before any TLS socket is created (not thread-safe, like
// SetStunCrypto); nullptr removes it.
using SslAdapterFactoryFn = std::unique_ptr<SslAdapter> (*)(std::unique_ptr<Socket> socket);
void SetSslAdapterFactory(SslAdapterFactoryFn factory);

}  // namespace sm::p2p
```

```cpp
namespace sm::p2p {

class TlsSslAdapter final : public SslAdapter {
 public:
  explicit TlsSslAdapter(std::unique_ptr<Socket> socket);
  ~TlsSslAdapter() override;

  // SslAdapter.
  void SetIgnoreBadCert(bool ignore) override { ignore_bad_cert_ = ignore; }
  void SetAlpnProtocols(const std::vector<std::string>& protocols) override { alpn_protocols_ = protocols; }
  void SetEllipticCurves(const std::vector<std::string>& curves) override { elliptic_curves_ = curves; }
  void SetCertVerifier(SslCertificateVerifier* verifier) override { cert_verifier_ = verifier; }
  void SetRole(SslRole role) override { role_ = role; }
  void AddTrustedRoot(std::vector<uint8_t> der) override { trusted_roots_.push_back(std::move(der)); }
  int StartSSL(std::string_view hostname) override;
  bool IsResumedSession() override { return false; }
  // SetIdentity: the certificate this end presents (a server needs one).
  void SetIdentity(std::unique_ptr<tls::SslIdentity> identity) { identity_ = std::move(identity); }
  // Whether to add the system's roots to the trusted ones (default true).
  void SetLoadSystemRoots(bool load) { load_system_roots_ = load; }

  // The engine, once the handshake has begun: version, ALPN, SNI; nullptr before.
  const tls::TlsStream* tls() const { return tls_.get(); }

  // Socket (AsyncSocketAdapter's forwarding, with OpenSSLAdapter's overrides).
  SocketAddress GetLocalAddress() const override { return socket_->GetLocalAddress(); }
  SocketAddress GetRemoteAddress() const override { return socket_->GetRemoteAddress(); }
  int Bind(const SocketAddress& addr) override { return socket_->Bind(addr); }
  int Connect(Timestamp now, const SocketAddress& addr) override {
    last_now_ = now;
    return socket_->Connect(now, addr);
  }
  int Send(Timestamp now, std::span<const uint8_t> data) override;
  int Recv(Timestamp now, std::span<uint8_t> buffer) override;
  int Close() override;
  int GetError() const override { return socket_->GetError(); }
  void SetError(int error) override { socket_->SetError(error); }
  ConnState GetState() const override;
  int GetOption(SocketOption opt, int* value) override { return socket_->GetOption(opt, value); }
  int SetOption(SocketOption opt, int value) override { return socket_->SetOption(opt, value); }

};

// Installs TlsSslAdapter with SetSslAdapterFactory(). Call once at startup.
void InstallSslAdapterFromTls();

}  // namespace sm::p2p
```
