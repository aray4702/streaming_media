# 2.4 SRTP and SRTCP (libsrtp)

Section 2, *Security*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Protecting media from eavesdropping and replay -> AES-CM-128-HMAC-SHA1-80 and AES-GCM with replay protection

## The issue

Media packets must be encrypted and authenticated, and a replayed packet must be dropped. SRTP does this per packet with a rolling counter, a tag and a replay window; RTCP has its own variant. The transports have to apply it at the right layer (after packetization, before the network) and re-key after a DTLS restart.

## Design

SRTP for DTLS-SRTP: libwebrtc's pc/srtp_session.{h,cc} (M157) on libsrtp 2.8.0, ported for milestone 3 (C5 part 1, #995). One SrtpSession protects what this end sends (SetSend) or unprotects what it receives (SetReceive), never both, as in libwebrtc. libsrtp is initialized on the first session that sets a key and shut down when the last one goes, as libwebrtc's LibSrtpInitializer does.

libwebrtc's policy, kept as is (SrtpSession::DoSetKey): the crypto suite's libsrtp profile for RTP and RTCP, a replay window of 1024 packets, retransmission of an already protected index allowed (allow_repeat_tx), the encrypted header extension ids (RFC 6904) unless cryptex (RFC 9335) is on, and no MKI.

Differences from libwebrtc, none of them in what goes on the wire: - Buffers are a span with its capacity and the used length (or a std::vector that grows), not a

```
  CopyOnWriteBuffer; the span form keeps libwebrtc's capacity check.
```

- libwebrtc's UMA histograms (WebRTC.PeerConnection.SrtpUnprotectError, SrtcpUnprotectError) are counters and the

```
  last libsrtp error code here; its throttled log lines and the RTP dump field trial are left out.
```

- No SequenceChecker: like every module in the library, a session is used from one thread at a time. The libsrtp

```
  init count is process-wide and takes a lock, as libwebrtc's does.
```

SRTP over an RTP transport: libwebrtc's pc/srtp_transport.{h,cc} at M157 (compare/webrtc/reference/), ported for DTLS-SRTP (C5 part 3, #1007) on sm::tls::SrtpSession (#995).

What it does, as libwebrtc does: - It is active once SetRtpParams has created the send and receive sessions; until then nothing is sent and every

```
  received packet is dropped. RTP goes through the RTP sessions, and RTCP too unless SetRtcpParams made separate
  RTCP sessions (non-muxed RTCP runs its own DTLS handshake, so its own keys).
```

- SetRtpParams again updates the existing sessions' keys (srtp_update), as a DTLS restart's re-keying does; a

```
  failure resets every session. SetRtcpParams works once.
```

- Replay protection, the auth tag and the crypto suites are SrtpSession's (libwebrtc's policy). Encrypted header

```
  extensions (RFC 6904) are used only for the ids the caller passes, none by default; cryptex is off by default.
```

- Writable is SRTP active and the packet transports writable; the writable signal fires on a change. - Unprotect failures are counted (and logged every 100th, as libwebrtc throttles them).

Differences from libwebrtc, none of them on the wire: those in sm/pc/rtp_transport.h, and libwebrtc's two field trials are an options struct, both off by default as in M157 (experiments/field_trials.py): WebRTC-SrtpRemoveReceiveStream (RemoveReceiveStream below) and WebRTC-UpdateNetworkRouteOnSrtpActivation (left out with the network route).

The RTP transport: libwebrtc's pc/rtp_transport.{h,cc} and pc/rtp_transport_internal.h at M157 (compare/webrtc/reference/), ported for DTLS-SRTP (C5 part 3, #1007). It sends and receives the RTP and RTCP of one RTP session over a packet transport (ICE, or DTLS over ICE), with or without rtcp-mux, and hands each received RTP packet to the sink the RtpDemuxer picks (sm::sync::RtpDemuxer, libwebrtc's call/rtp_demuxer.cc).

What it does, as libwebrtc does: - With rtcp-mux, RTP and RTCP share the RTP packet transport; without, RTCP goes over its own. - A received packet is classified by its payload-type byte (RFC 5761): RTCP goes to the RTCP subscribers, RTP is

```
  parsed with the header extensions registered for the session (by MID, newest registration first on an id
  conflict, RFC 8843 section 7.1.3) and demultiplexed; a packet no sink takes goes to the undemuxable handler.
  Packets that are neither, of a bad size, or DTLS application data are dropped.
```

- Ready to send is the RTP transport's, and the RTCP transport's too without rtcp-mux; writable likewise.

The library's time model: nothing reads a clock or starts a thread. Sending takes `now` (the packet transport's SendPacket does), and callbacks run on the caller's thread inside the call that caused them.

Differences from libwebrtc, none of them on the wire: - Packets are std::vector<uint8_t> (protected in place, growing for the SRTP trailer), not CopyOnWriteBuffer, and

```
  a received RTP packet reaches its sink as RtpPacketReceived (the bytes and the parsed sm::RtpPacket).
```

- The network route (SubscribeNetworkRouteChanged, and the SRTP overhead SrtpTransport adds to it behind the

```
  WebRTC-UpdateNetworkRouteOnSrtpActivation field trial, off by default) is left out until ICE reports candidate
  pairs (#1002), as in sm/p2p/packet_transport_internal.h.
```

- ECN is left out: the packet transports don't report it yet, so RTCP is never sent as ECT(1). - A ready-to-send change during a ready-to-send callback is re-checked when that callback returns; libwebrtc posts

```
  it as a task to the same thread.
```

- RTCError results are bool. - No SequenceChecker: like every module in the library, a transport is used from one thread at a time.

libwebrtc M157 counterpart: `pc/srtp_session.{h,cc}`, `pc/srtp_transport.{h,cc}`, `pc/rtp_transport.{h,cc}`, `pc/rtp_utils.{h,cc}`. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.7](../../design/libwebrtc-parity.md#107-srtp-and-dtls-srtp-transports-srcpcrtp_transportsrtp_transportdtls_srtp_transportcc-c5-part-3-1007). Requirement C5. The test bench keeps unencrypted media.

namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

class DtlsTransport;

// libsrtp status codes the tests and callers look at (srtp_err_status_t).
inline constexpr int kSrtpErrOk = 0;
inline constexpr int kSrtpErrBadParam = 2;
inline constexpr int kSrtpErrAuthFail = 7;
inline constexpr int kSrtpErrReplayFail = 9;
inline constexpr int kSrtpErrCantCheck = 14;
inline constexpr int kSrtpErrCryptex = 28;

// Prohibits this library from initializing libsrtp, when another library in the process does (libwebrtc's
// ProhibitLibsrtpInitialization). Call it before the first session sets a key.
void ProhibitLibsrtpInitialization();

class SrtpSession {
 public:
  SrtpSession() = default;
  ~SrtpSession();
  SrtpSession(const SrtpSession&) = delete;
  SrtpSession& operator=(const SrtpSession&) = delete;

  // Enables or disables cryptex (RFC 9335); may update an existing session.
  bool UseCryptex(bool enabled, bool require, bool sending_session);

  // The crypto suite (sm::tls::kSrtp*) and the master key followed by the master salt. False if the suite is
  // unknown, the key has the wrong length, or (Set*) the session already has a key.
  bool SetSend(int crypto_suite, std::span<const uint8_t> key, const std::vector<int>& extension_ids = {});
  bool UpdateSend(int crypto_suite, std::span<const uint8_t> key, const std::vector<int>& extension_ids = {});
  bool SetReceive(int crypto_suite, std::span<const uint8_t> key, const std::vector<int>& extension_ids = {});
  bool UpdateReceive(int crypto_suite, std::span<const uint8_t> key, const std::vector<int>& extension_ids = {});

  // Protects the packet in buffer[0, len) in place; `buffer` is the whole space available. False (and nothing
  // changed) if the space can't take the auth tag (and, for RTCP, the 4-byte SRTCP index) or libsrtp refuses it.
  // On success `len` is the protected length. `index`, if given, gets the packet's SRTP index as libwebrtc
  // reports it (the extended sequence number shifted left 16 bits, in network byte order).
  bool ProtectRtp(std::span<uint8_t> buffer, size_t& len, int64_t* index = nullptr);
  bool ProtectRtcp(std::span<uint8_t> buffer, size_t& len);
  // Verifies and decrypts buffer[0, len) in place; on success `len` is the plain length.
  bool UnprotectRtp(std::span<uint8_t> buffer, size_t& len);
  bool UnprotectRtcp(std::span<uint8_t> buffer, size_t& len);

  // The same on a std::vector, which grows to take the trailer.
  bool ProtectRtp(std::vector<uint8_t>& packet, int64_t* index = nullptr);
  bool ProtectRtcp(std::vector<uint8_t>& packet);
  bool UnprotectRtp(std::vector<uint8_t>& packet);
  bool UnprotectRtcp(std::vector<uint8_t>& packet);

  // The RTP auth tag length in bytes: what protecting adds to an RTP packet (GetSrtpOverhead).
  int GetSrtpOverhead() const { return rtp_auth_tag_len_; }

  // Removes a received SSRC's state (replay window, rollover counter). Only for SSRCs that are received: reusing a
  // sent SSRC with the same key breaks SRTP (RFC 3711 section 8).
  bool RemoveSsrcFromSession(uint32_t ssrc);

  // Unprotect failures so far, and the libsrtp status of the last one (libwebrtc's histograms).
  int rtp_unprotect_failures() const { return decryption_failure_count_; }
  int rtcp_unprotect_failures() const { return rtcp_decryption_failure_count_; }
  int last_rtp_unprotect_error() const { return last_rtp_error_; }
  int last_rtcp_unprotect_error() const { return last_rtcp_error_; }

};

// The SRTP keys for one end of a DTLS-SRTP association: libwebrtc's DtlsSrtpTransport::ExtractParams. The RFC 5764
// keying material (client key | server key | client salt | server salt) is split into key+salt per direction, and
// the DTLS role picks which one this end sends with. The keys are zeroed when the object goes (ZeroOnFreeBuffer).
struct SrtpKeys {
  int crypto_suite = 0;
  std::vector<uint8_t> send_key;  // master key followed by master salt
  std::vector<uint8_t> recv_key;
  SrtpKeys() = default;
  SrtpKeys(const SrtpKeys&) = delete;
  SrtpKeys& operator=(const SrtpKeys&) = delete;
  ~SrtpKeys();
};
// False if the transport isn't connected, no SRTP profile was negotiated, or the export fails.
bool ExtractSrtpKeys(const DtlsTransport& dtls, SrtpKeys& keys);

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls

namespace sm::pc {

struct SrtpTransportOptions {
  // WebRTC-SrtpRemoveReceiveStream: unregistering a demuxer sink also removes its signalled SSRCs from the
  // receive session (replay window and rollover counter).
  bool remove_receive_stream = false;
};

class SrtpTransport : public RtpTransport {
 public:
  explicit SrtpTransport(bool rtcp_mux_enabled, SrtpTransportOptions options = {});
  ~SrtpTransport() override;

  // Protects the packet, then sends it; false (nothing sent) while SRTP is inactive or if protection fails.
  bool SendRtpPacket(std::vector<uint8_t>& packet, const p2p::PacketOptions& options, int flags,
                     Timestamp now) override;
  bool SendRtcpPacket(std::vector<uint8_t>& packet, const p2p::PacketOptions& options, int flags,
                      Timestamp now) override;

  // Active once the send and receive sessions exist.
  bool IsSrtpActive() const override;
  bool IsWritable(bool rtcp) const override;

  // Enables or disables cryptex (RFC 9335) on the existing sessions and the ones made later.
  bool UseCryptex(bool enable, bool require);

  // Creates the RTP send/receive sessions with the negotiated suite and key (master key then salt) and the
  // encrypted header extension ids, or updates their keys if they exist (from SDES, or the DTLS export).
  bool SetRtpParams(int send_crypto_suite, const std::vector<uint8_t>& send_key,
                    const std::vector<int>& send_extension_ids, int recv_crypto_suite,
                    const std::vector<uint8_t>& recv_key, const std::vector<int>& recv_extension_ids);
  // Creates separate RTCP sessions (non-muxed RTCP). Only once.
  bool SetRtcpParams(int send_crypto_suite, const std::vector<uint8_t>& send_key,
                     const std::vector<int>& send_extension_ids, int recv_crypto_suite,
                     const std::vector<uint8_t>& recv_key, const std::vector<int>& recv_extension_ids);
  void ResetParams();

  // The bytes protection adds to an RTP packet (the auth tag); false while inactive.

  bool UnregisterRtpDemuxerSink(RtpPacketSinkInterface* sink) override;

  // Received packets that failed to unprotect.
  int rtp_decryption_failures() const { return decryption_failure_count_; }
  int rtcp_decryption_failures() const { return rtcp_decryption_failure_count_; }

 protected:
  // If the writable state changed, fires the writable signal.
  void MaybeUpdateWritableState();

  void OnRtpPacketReceived(const p2p::ReceivedPacket& packet) override;
  void OnRtcpPacketReceived(const p2p::ReceivedPacket& packet) override;
  void OnWritableState(p2p::PacketTransportInternal* packet_transport) override;

};

// libwebrtc's RtpTransportInternal: the interface BaseChannel uses, with its signals.
class RtpTransportInternal {
 public:
  using RtcpCallback = std::function<void(const std::vector<uint8_t>& packet, std::optional<Timestamp> arrival)>;
  using BoolCallback = std::function<void(bool)>;
  using SentCallback = std::function<void(const p2p::SentPacketInfo&)>;
  using UndemuxableCallback = std::function<void(const RtpPacketReceived&)>;

  virtual ~RtpTransportInternal() = default;
  virtual void SetRtcpMuxEnabled(bool enable) = 0;
  virtual const std::string& transport_name() const = 0;
  virtual int SetRtpOption(p2p::SocketOption opt, int value) = 0;
  virtual int SetRtcpOption(p2p::SocketOption opt, int value) = 0;
  virtual bool rtcp_mux_enabled() const = 0;
  virtual bool IsReadyToSend() const = 0;
  virtual bool IsWritable(bool rtcp) const = 0;
  // Sends one packet; `packet` may be changed (protected in place). False if it wasn't sent whole.
  virtual bool SendRtpPacket(std::vector<uint8_t>& packet, const p2p::PacketOptions& options, int flags,
                             Timestamp now) = 0;
  virtual bool SendRtcpPacket(std::vector<uint8_t>& packet, const p2p::PacketOptions& options, int flags,
                              Timestamp now) = 0;
  virtual bool RegisterRtpHeaderExtensionMap(std::string_view mid, const RtpHeaderExtensions& extensions) = 0;
  virtual bool VerifyRtpHeaderExtensionMap(const RtpHeaderExtensions& extensions) const = 0;
  virtual void UnregisterRtpHeaderExtensionMap(std::string_view mid) = 0;
  virtual bool IsSrtpActive() const = 0;
  virtual bool RegisterRtpDemuxerSink(const RtpDemuxerCriteria& criteria, RtpPacketSinkInterface* sink) = 0;
  virtual bool UnregisterRtpDemuxerSink(RtpPacketSinkInterface* sink) = 0;
  virtual void SetActivePayloadTypeDemuxing(bool enabled) = 0;

  // True when every transport in use is ready to send (more specific than writable).
  void SubscribeReadyToSend(const void* tag, BoolCallback cb) { ready_to_send_.Add(tag, std::move(cb)); }
  void UnsubscribeReadyToSend(const void* tag) { ready_to_send_.Remove(tag); }
  // Each received (unprotected) RTCP packet.
  void SubscribeRtcpPacketReceived(const void* tag, RtcpCallback cb) { rtcp_received_.Add(tag, std::move(cb)); }
  // A received RTP packet that no sink takes.
  void SetUnDemuxableRtpPacketReceivedHandler(UndemuxableCallback cb) { undemuxable_ = std::move(cb); }
  // The writable state may have changed.
  void SubscribeWritableState(const void* tag, BoolCallback cb) { writable_state_.Add(tag, std::move(cb)); }
  void UnsubscribeWritableState(const void* tag) { writable_state_.Remove(tag); }
  void SubscribeSentPacket(const void* tag, SentCallback cb) { sent_packet_.Add(tag, std::move(cb)); }
  void UnsubscribeSentPacket(const void* tag) { sent_packet_.Remove(tag); }

 protected:
  void SendReadyToSend(bool ready) { ready_to_send_.Send(ready); }
  void SendRtcpPacketReceived(const std::vector<uint8_t>& packet, std::optional<Timestamp> arrival) {
    rtcp_received_.Send(packet, arrival);
  }
  void NotifyUnDemuxableRtpPacketReceived(const RtpPacketReceived& packet) {
    if (undemuxable_) undemuxable_(packet);
  }
  void SendWritableState(bool writable) { writable_state_.Send(writable); }
  void SendSentPacket(const p2p::SentPacketInfo& info) { sent_packet_.Send(info); }

};

  bool IsWritable(bool rtcp) const override;
  bool SendRtpPacket(std::vector<uint8_t>& packet, const p2p::PacketOptions& options, int flags,

Every class implements `MetricsSource::ExportMetrics`, so it can be registered in a `MetricsRegistry` and exported as JSON or Prometheus text. Histograms expand to `.count/.mean/.p50/.p95/.p99/.max`.
