# 2.1 TLS/DTLS interface and its BoringSSL and mbedTLS backends

Section 2, *Security*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Encrypting and authenticating a connection -> libwebrtc's `SSLIdentity`, `SSLFingerprint`, `MessageDigest` and `CryptoRandom` interfaces, two backends

## The issue

Media must be encrypted and the peer's identity checked. WebRTC does it with DTLS and certificates whose fingerprint travels in SDP. A library for small devices and for browsers cannot depend on one TLS implementation, so the code is behind one interface with two backends (BoringSSL and mbedTLS) that have to interoperate and agree on the DTLS version.

## Design

The TLS backend sm::tls is built on (#998): BoringSSL, as libwebrtc M157 builds, or Mbed TLS for microcontrollers (C1, decided on #944). CMake picks it with SM_TLS_BACKEND=boringssl|mbedtls and sets SM_TLS_BACKEND_MBEDTLS on every target that links an mbedTLS build of sm::tls.

Each backend's API lives in its own inline namespace (sm::tls::boringssl_backend, sm::tls::mbedtls_backend). Callers still write sm::tls::DtlsTransport; the inline namespace only gives the two builds distinct symbols, so a BoringSSL build and an mbedTLS build can link into one binary (the cross test, tests/unit/tls/cross_test.cc).

A DTLS identity: a key pair and a self-signed X.509 certificate. libwebrtc's rtc_base/ssl_identity.h, ssl_certificate.h and boringssl_identity/boringssl_certificate (M157), ported for milestone 3 (#984 part 1b). WebRTC endpoints make one per connection (or reuse one); its SHA-256 fingerprint goes in SDP's a=fingerprint and the peer checks the DTLS certificate against it.

A certificate fingerprint, as SDP's a=fingerprint carries it: libwebrtc's rtc_base/ssl_fingerprint.h (M157), ported for milestone 3 (#984 part 1b).

Message digests and HMAC: libwebrtc's rtc_base/message_digest.h (M157), ported for the connectivity layer (milestone 3, #984). STUN's MESSAGE-INTEGRITY (HMAC-SHA1), TURN's long-term key (MD5) and the certificate fingerprints in SDP (SHA-256) use it. The digests come from the TLS backend (BoringSSL, or mbedTLS with SM_TLS_BACKEND=mbedtls, #998).

Cryptographically secure random data: libwebrtc's rtc_base/crypto_random.h (M157), for ICE credentials, STUN transaction ids and DTLS (milestone 3, #984). The generator is the TLS backend's (BoringSSL's RAND_bytes, or mbedTLS's PSA generator, #998). A test mode makes the output a fixed sequence, as libwebrtc's SetRandomTestMode.

libwebrtc M157 counterpart: `rtc_base/{ssl_identity,ssl_certificate,ssl_fingerprint,message_digest,crypto_random}.{h,cc}`, `rtc_base/openssl_*`. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.2](../../design/libwebrtc-parity.md#102-tls-backend-mbed-tls-srctlsmbedtls_cc-c1-part-3-998). Requirement C1. Each backend reports the DTLS versions it supports and a handshake agrees on the highest both have (BoringSSL 1.3, mbedTLS 1.2). Not built for wasm (`SM_WITH_TLS` is off there).

```cpp
namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

// KeyType: libwebrtc's default is ECDSA (P-256), which browsers use too.
enum class KeyType { kRsa, kEcdsa };
inline constexpr int kRsaDefaultModSize = 2048;  // ssl_identity.h
inline constexpr int64_t kDefaultCertificateLifetimeSeconds = 60 * 60 * 24 * 30;  // 30 days.
inline constexpr int64_t kCertificateWindowSeconds = -60 * 60 * 24;               // not_before: a day back.

struct SslIdentityParams {
  std::string common_name;
  int64_t not_before = 0;  // Seconds since the epoch.
  int64_t not_after = 0;
  KeyType key_type = KeyType::kEcdsa;
};

// An X.509 certificate, held as DER.
class SslCertificate {
 public:
  explicit SslCertificate(std::vector<uint8_t> der) : der_(std::move(der)) {}
  static std::unique_ptr<SslCertificate> FromPem(std::string_view pem);

  std::span<const uint8_t> der() const { return der_; }
  std::string ToPem() const;
  // The digest of the DER (ComputeDigest): false for an unknown algorithm.
  bool ComputeDigest(std::string_view algorithm, std::vector<uint8_t>& out) const;
  // The signature's digest algorithm, from its OID ("sha-256" for an ECDSA-SHA256 certificate): the algorithm the
  // fingerprint uses (SSLFingerprint::CreateFromCertificate). False if the OID is not one libwebrtc knows.
  bool GetSignatureDigestAlgorithm(std::string& algorithm) const;
  // The validity's notAfter, in seconds since the epoch, or -1.
  int64_t CertificateExpirationTime() const;

  bool operator==(const SslCertificate& o) const { return der_ == o.der_; }

};

class SslIdentity {
 public:
  // A new key pair and a certificate valid from a day ago for `lifetime_s` (SSLIdentity::Create). Null on failure.
  static std::unique_ptr<SslIdentity> Create(std::string_view common_name, KeyType key_type = KeyType::kEcdsa,
                                             int64_t lifetime_s = kDefaultCertificateLifetimeSeconds);
  static std::unique_ptr<SslIdentity> CreateForTest(const SslIdentityParams& params);
  // From a PKCS#8 or SEC1/PKCS#1 private key and a certificate, both PEM (CreateFromPEMStrings). Null if they don't
  // parse or don't match.
  static std::unique_ptr<SslIdentity> CreateFromPem(std::string_view private_key_pem, std::string_view certificate_pem);

  virtual ~SslIdentity() = default;
  virtual const SslCertificate& certificate() const = 0;
  virtual std::string PrivateKeyToPem() const = 0;
  virtual std::string PublicKeyToPem() const = 0;
  virtual std::unique_ptr<SslIdentity> Clone() const = 0;
  // The backend's key (an EVP_PKEY* for BoringSSL, an mbedtls_pk_context* for mbedTLS), for the DTLS adapter (#984 part 2).
  virtual void* native_key() const = 0;
};

bool operator==(const SslIdentity& a, const SslIdentity& b);

// PEM <-> DER (SSLIdentity::PemToDer / DerToPem): `type` is the label, e.g. "CERTIFICATE".
bool PemToDer(std::string_view type, std::string_view pem, std::vector<uint8_t>& der);
std::string DerToPem(std::string_view type, std::span<const uint8_t> der);

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls
```

```cpp
namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

struct SslFingerprint {
  SslFingerprint(std::string_view alg, std::span<const uint8_t> d) : algorithm(alg), digest(d.begin(), d.end()) {}

  // The digest of `cert` with `algorithm`; null for an unknown algorithm.
  static std::unique_ptr<SslFingerprint> Create(std::string_view algorithm, const SslCertificate& cert);
  static std::unique_ptr<SslFingerprint> Create(std::string_view algorithm, const SslIdentity& identity);
  // From SDP: a FIPS 180 algorithm and "AB:CD:..." hex (CreateFromRfc4572); null if either is malformed.
  static std::unique_ptr<SslFingerprint> CreateFromRfc4572(std::string_view algorithm, std::string_view fingerprint);
  // With the certificate's own signature digest algorithm (CreateFromCertificate).
  static std::unique_ptr<SslFingerprint> CreateFromCertificate(const SslIdentity& identity);

  // "AB:CD:..." upper case, as SDP writes it.
  std::string GetRfc4572Fingerprint() const;
  // "sha-256 AB:CD:...".
  std::string ToString() const;
  bool operator==(const SslFingerprint& o) const { return algorithm == o.algorithm && digest == o.digest; }

  std::string algorithm;
  std::vector<uint8_t> digest;
};

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls
```

```cpp
namespace sm::tls {
inline namespace SM_TLS_BACKEND_NS {

// The algorithm names, as RFC 4572 / SDP a=fingerprint spells them (message_digest.cc).
inline constexpr char kDigestMd5[] = "md5";
inline constexpr char kDigestSha1[] = "sha-1";
inline constexpr char kDigestSha224[] = "sha-224";
inline constexpr char kDigestSha256[] = "sha-256";
inline constexpr char kDigestSha384[] = "sha-384";
inline constexpr char kDigestSha512[] = "sha-512";

class MessageDigest {
 public:
  static constexpr size_t kMaxSize = 64;  // SHA-512.
  virtual ~MessageDigest() = default;
  // The digest output size (16 for MD5, 20 for SHA-1).
  virtual size_t Size() const = 0;
  virtual void Update(const void* buf, size_t len) = 0;
  // Writes the digest to `buf` (at least Size() bytes) and resets for the next one. Returns the bytes written, or 0
  // if `len` is too small.
  virtual size_t Finish(void* buf, size_t len) = 0;
};

// MessageDigestFactory::Create: null for an unknown algorithm.
std::unique_ptr<MessageDigest> CreateMessageDigest(std::string_view alg);

// RFC 4572 section 5: the FIPS 180 algorithms a self-signed certificate's fingerprint must use.
bool IsFips180DigestAlgorithm(std::string_view alg);

// The digest of `input` into `output`; the bytes written, or 0 for an unknown algorithm or a short `output`.
size_t ComputeDigest(std::string_view alg, std::span<const uint8_t> input, std::span<uint8_t> output);
// The digest of `input`, hex-encoded (lower case); empty for an unknown algorithm.
std::string ComputeDigest(std::string_view alg, std::string_view input);

// RFC 2104 HMAC, as libwebrtc computes it (for digests with a 64-byte block: MD5, SHA-1, SHA-224, SHA-256). The
// bytes written, or 0 for an unknown or unsupported algorithm or a short `output`.
size_t ComputeHmac(std::string_view alg, std::span<const uint8_t> key, std::span<const uint8_t> input,
                   std::span<uint8_t> output);
// The HMAC of `input` with `key`, hex-encoded; empty for an unknown or unsupported algorithm.
std::string ComputeHmac(std::string_view alg, std::string_view key, std::string_view input);

}  // namespace SM_TLS_BACKEND_NS
}  // namespace sm::tls
```
