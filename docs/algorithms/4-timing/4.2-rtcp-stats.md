# 4.2 RTCP statistics: loss, jitter and RTT

Section 4, *Jitter, reordering and timing*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Measuring network delay -> RTCP SR/RR (RTT, jitter), transport-wide feedback, abs-send-time

## The issue

Every adaptive decision needs measurements of the network: the round-trip time (to time retransmissions and choose FEC), the loss rate (for protection and bandwidth estimation) and the jitter (for buffer sizing). Neither side can measure these alone. The receiver sees loss and jitter but not RTT. The sender knows when it sent but not when packets arrived. Clocks on the two machines are not synchronized, so one-way delay cannot be measured directly at all.

RTCP sender and receiver reports solve this by echoing timestamps. Their fixed-point formats, 32-bit wrap-around and the rule that "fraction lost" refers only to the interval since the previous report are easy to get subtly wrong.

## Design

jitter, extended highest sequence number), RTCP SR/RR wire format, and RTT from report blocks (LSR/DLSR).

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#4-jitter-and-timing) for the differences from libwebrtc. Implements RFC 3550 A.3 (expected/lost/fraction) and A.8 (interarrival jitter, 1/16 gain) and the SR/RR wire format. Transport-wide feedback and abs-send-time are in 5.1 and 8.4.

## Implementation skeleton

Files: [include/sm/timing/rtcp_stats.h](../../../include/sm/timing/rtcp_stats.h), [src/timing/rtcp_stats.cc](../../../src/timing/rtcp_stats.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::timing {

// 64-bit NTP timestamp (seconds since 1900 in 32.32 fixed point). The
// library's Timestamp is interpreted as time since the Unix epoch.
struct NtpTime {
  uint64_t value = 0;
  static NtpTime FromTimestamp(Timestamp t);
  Timestamp ToTimestamp() const;
  // Middle 32 bits, used by LSR/DLSR.
  uint32_t Compact() const { return static_cast<uint32_t>(value >> 16); }
};
TimeDelta CompactNtpToDelta(uint32_t compact);  // 16.16 seconds -> TimeDelta.

struct ReportBlock {
  uint32_t ssrc = 0;
  uint8_t fraction_lost = 0;     // Q8.
  int32_t cumulative_lost = 0;   // 24-bit signed on the wire.
  uint32_t extended_highest_seq = 0;
  uint32_t jitter = 0;           // RTP timestamp units.
  uint32_t last_sr = 0;          // Compact NTP of the last SR received.
  uint32_t delay_since_last_sr = 0;  // 1/65536 s.
};

struct SenderReport {
  uint32_t ssrc = 0;
  NtpTime ntp;
  uint32_t rtp_timestamp = 0;
  uint32_t packet_count = 0;
  uint32_t octet_count = 0;
  std::vector<ReportBlock> blocks;
};

struct ReceiverReport {
  uint32_t ssrc = 0;
  std::vector<ReportBlock> blocks;
};

std::vector<uint8_t> SerializeSenderReport(const SenderReport& sr);
std::vector<uint8_t> SerializeReceiverReport(const ReceiverReport& rr);
// Parses a single SR (PT 200) or RR (PT 201) packet.
std::optional<SenderReport> ParseSenderReport(std::span<const uint8_t> data);
std::optional<ReceiverReport> ParseReceiverReport(std::span<const uint8_t> data);

struct ReceiveStatsSnapshot {
  uint32_t packets_received = 0;
  int64_t expected = 0;
  int64_t cumulative_lost = 0;
  double fraction_lost = 0;  // Since the previous report.
  double jitter_ms = 0;
};

// Per-SSRC receive statistics as defined in RFC 3550 A.3 and A.8.
class ReceiveStatistics : public MetricsSource {
 public:
  ReceiveStatistics(uint32_t ssrc, int clock_rate) : ssrc_(ssrc), clock_rate_(clock_rate) {}
  void OnPacket(uint16_t seq, uint32_t rtp_ts, Timestamp arrival);
  void OnSenderReport(const SenderReport& sr, Timestamp arrival);
  // Builds a report block and starts a new fraction-lost interval.
  ReportBlock MakeReportBlock(Timestamp now);
  ReceiveStatsSnapshot Snapshot() const;
  double jitter_ms() const { return jitter_ / 16.0 * 1000.0 / clock_rate_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

// RTT from report blocks: RTT = A - LSR - DLSR (A = arrival, compact NTP).
class RttEstimator : public MetricsSource {
 public:
  std::optional<TimeDelta> OnReportBlock(const ReportBlock& rb, Timestamp arrival);
  TimeDelta last() const { return last_; }
  TimeDelta smoothed() const { return smoothed_; }
  TimeDelta min() const { return min_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::timing
```

## Metrics and observability

Every class implements `MetricsSource::ExportMetrics`, so it can be registered in a `MetricsRegistry` and exported as JSON or Prometheus text. Histograms expand to `.count/.mean/.p50/.p95/.p99/.max`.

| Metric | Type |
|---|---|
| `packets_received` | counter |
| `cumulative_lost` | gauge |
| `fraction_lost` | gauge |
| `jitter_ms` | gauge |
| `rtt_ms` | gauge |
| `smoothed_rtt_ms` | gauge |
| `samples` | counter |
| `rtt_hist_ms` | histogram |
