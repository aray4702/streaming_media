# 6.7 DTX and comfort noise (RFC 3389)

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Silence wasting bandwidth -> VAD + DTX (discontinuous transmission)
- Silence sounding 'dead' at the receiver -> CNG (comfort noise generation)

## The issue

In a conversation each participant is silent about half the time, yet a naive sender keeps encoding and sending background noise at full packet rate. That wastes bandwidth, radio power and battery (important on mobile and wearables) and network capacity in large calls.

Simply not sending during silence creates a new problem: the receiver plays digital silence, which sounds like the call dropped, and the background noise "pumps" on and off around each word. The receiver needs a compact description of the background noise (level and spectral shape), updated only when it changes, to synthesize comfort noise that sounds like the real room.

## Design

Sender: while the VAD reports silence, DtxController suppresses audio packets and instead emits a SID (silence insertion descriptor) on the speech->silence transition, whenever the background noise changes by more than `update_threshold_db` in level or spectrum (measured on an autocorrelation averaged over recent silent frames), and at least every `max_sid_interval` as a keep-alive. The SID carries the noise level (-dBov) and LPC reflection coefficients (order 10, Levinson-Durbin), quantized as in RFC 3389.

Receiver: ComfortNoiseGenerator shapes white noise with the all-pole LPC filter at the SID level, interpolating between SIDs, so silence sounds like the far room instead of a dead line.

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#6-audio-quality) for the differences from libwebrtc. SID reflection coefficients are interpolated between updates, so the synthesis filter is always stable.

## Implementation skeleton

Files: [include/sm/audio/comfort_noise.h](../../../include/sm/audio/comfort_noise.h), [src/audio/comfort_noise.cc](../../../src/audio/comfort_noise.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::audio {

struct SidFrame {
  uint8_t level = 127;  // -dBov, 0..127.
  std::vector<float> reflection;  // k_1..k_order, each in (-1, 1).
};

std::vector<uint8_t> EncodeSid(const SidFrame& sid);
std::optional<SidFrame> DecodeSid(std::span<const uint8_t> payload);
// Analyses a frame of background noise.
SidFrame AnalyzeNoise(std::span<const float> frame, int order = 10);
// Building blocks: windowed autocorrelation of a frame, and a SID from an
// (optionally averaged) autocorrelation plus mean power per sample.
std::vector<double> NoiseAutocorrelation(std::span<const float> frame, int order = 10);
SidFrame SidFromAutocorrelation(std::vector<double> r, double mean_power);

enum class DtxDecision { kSendSpeech, kSendSid, kSuppress };

struct DtxConfig {
  int max_sid_interval_ms = 400;
  float update_threshold_db = 3.0f;
  int frame_ms = 10;
  int hangover_frames = 0;  // Extra speech frames after the VAD turns off.
};

struct DtxStats {
  uint64_t frames = 0, speech = 0, sid = 0, suppressed = 0;
};

class DtxController : public MetricsSource {
 public:
  explicit DtxController(DtxConfig cfg = {}) : cfg_(cfg) {}
  // Returns what to send for this frame; `sid_out` is filled for kSendSid.
  DtxDecision Process(std::span<const float> frame, bool speech, SidFrame* sid_out);
  const DtxStats& stats() const { return stats_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

class ComfortNoiseGenerator : public MetricsSource {
 public:
  explicit ComfortNoiseGenerator(uint64_t seed = 99) : rng_(seed) {}
  void OnSid(const SidFrame& sid);
  void Generate(std::span<float> out);
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::audio
```

**Unit tests** (deterministic, no network):

- `ComfortNoise`: `SidRoundTripAndLevel`, `GeneratedNoiseMatchesLevelAndSpectrum`, `DtxDecisions`

**End-to-end test** (sender -> simulated network -> receiver, `tests/e2e/`):

- `E2E_ComfortNoise`: `DtxSavesPacketsCngFillsSilence`

A one-sided stretch of a call (talks 15 s, listens 15 s) at -50 dBFS background noise; speech frames and SIDs cross a 2%-loss link. Transmitted-frame ratio against the actual speech ratio, and comfort-noise level against the real noise in pauses.

## Verification notes

Defect found: SIDs were sent too often, because spectral-change detection used single-frame reflection coefficients (sigma about 0.08). The background description now comes from an averaged autocorrelation, and the transmit ratio fell from 0.65 to 0.49 (speech 0.43). A measurement bug that counted lost speech packets as silence was also fixed.
