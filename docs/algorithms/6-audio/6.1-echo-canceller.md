# 6.1 Acoustic echo cancellation

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Echo (far-end audio coming back through the mic) -> AEC3 acoustic echo canceller; AECM for mobile

## The issue

On a speakerphone, laptop or conference device, the far end's voice comes out of the loudspeaker, bounces around the room and enters the microphone. Without cancellation the far-end talker hears themselves 100-500 ms later, which makes conversation nearly impossible. At high gain the loop can turn into howling feedback.

The echo is not a simple delayed copy: the room filters it through tens to hundreds of milliseconds of reflections, which change when someone moves. The canceller must learn this response continuously from the signal itself. It must not learn from the local talker's voice when both people speak at once (double talk), or it will cancel the local voice instead. Whatever the linear model cannot capture (loudspeaker distortion, model error) must be suppressed without muting the local talker.

## Design

Linear stage: partitioned-block frequency-domain NLMS (PBFDAF / MDF). Blocks of B = 5 ms, FFT N = next_pow2(2B), P partitions of B taps cover `filter_length_ms` of echo tail after the bulk delay found by EchoDelayEstimator. Each partition's gradient is constrained to B taps (overlap-save), and the step is normalized per frequency bin by the far-end power summed over partitions.

Step size: after initial convergence the NLMS step follows the residual-echo-to-error ratio (Valin 2007), mu = mu0 * min(1, leak * |y|^2 / |e|^2); near-end speech inflates |e|^2, so adaptation nearly stops during double talk without an explicit detector.

Double talk: two filters (Speex MDF style). The background filter always adapts; the foreground filter (which produces the output) receives the background's coefficients only when the background's error-energy improvement is statistically significant: its mean, at two time constants, must exceed a multiple of its variance (estimated from the foreground error energy times the energy of the difference between the two errors). Near-end speech makes that difference noisy, so a background filter disturbed by double talk is not copied; a significantly worse background is reset from the foreground.

Residual echo suppression: the linear filter leaves residual echo (non-linearities, model mismatch). A second STFT stage estimates the residual as leak * |Y(k)|^2, where the leak is the correlation between error and echo-estimate power spectra over time (near speech is uncorrelated with the far end, so double talk does not inflate it), and applies a suppression gain per bin.

// aec3_common.h
constexpr size_t kFftLengthBy2Plus1 = kFftLengthBy2 + 1;
constexpr size_t kFftLengthBy2Minus1 = kFftLengthBy2 - 1;
constexpr size_t kFftLength = 2 * kFftLengthBy2;
constexpr size_t kBlockSizeMs = kFftLengthBy2 * 1000 / 16000;

// log2 of in > 0 from its bits, in a fast and approximate manner.
inline float FastApproxLog2f(const float in) {
  float out = static_cast<float>(std::bit_cast<uint32_t>(in));
  out *= 1.1920929e-7f;  // 1/2^23
  out -= 126.942695f;    // Remove bias.
  return out;
}
constexpr size_t NumBandsForRate(int sample_rate_hz) { return static_cast<size_t>(sample_rate_hz / 16000); }

  return filter_length_blocks * static_cast<int>(kFftLengthBy2);
}

                                          size_t filter_length_blocks) {
  return GetDownSampledBufferSize(down_sampling_factor, num_matched_filters) / (kBlockSize / down_sampling_factor) +

template <typename T>
struct RingBuffer {
  RingBuffer(size_t n, const T& init) : size(static_cast<int>(n)), buffer(n, init) {}
  int IncIndex(int index) const { return index < size - 1 ? index + 1 : 0; }
  int DecIndex(int index) const { return index > 0 ? index - 1 : size - 1; }
  int OffsetIndex(int index, int offset) const { return (size + index + offset) % size; }
  void UpdateWriteIndex(int offset) { write = OffsetIndex(write, offset); }
  void IncWriteIndex() { write = IncIndex(write); }
  void DecWriteIndex() { write = DecIndex(write); }
  void UpdateReadIndex(int offset) { read = OffsetIndex(read, offset); }
  void IncReadIndex() { read = IncIndex(read); }
  void DecReadIndex() { read = DecIndex(read); }
  const int size;
  std::vector<T> buffer;
  int write = 0;
  int read = 0;
};
struct BlockBuffer : RingBuffer<Block> {
  BlockBuffer(size_t n, size_t num_bands, size_t num_channels)
      : RingBuffer(n, Block(static_cast<int>(num_bands), static_cast<int>(num_channels))) {}
};

## Verification notes

Several defects were found and fixed. (1) The delay estimate was wrong (see 6.2), which capped ERLE at 12 dB. (2) Double talk corrupted the filter: the background filter partly 'cancels' near speech for a few blocks and was then copied to the foreground. An ERLE-based double-talk detector was tried and rejected (it fired on 40% of far-end-only blocks). The final design uses Speex's statistical copy rule plus Valin's adaptive step size, which collapses during double talk (step 0.35 -> 0.002): near-end SNR went from -4 to +9 dB. (3) After an echo-path change the convergence state was not reset, so the adaptive step stayed near zero and ERLE never recovered (0 dB); it now recovers to 25.6 dB. AEC3's linear stage (#240 step 2): libwebrtc's aec3_fft, render_delay_buffer, adaptive_fir_filter (FilterSize, FilterStatisticsAccess, FilterAndAdapt), coarse_filter_update_gain, refined_filter_update_gain and subtractor unit tests pass with their signals and bounds (multi-channel cases with the debug-build parameters; the SIMD-equivalence and death tests don't apply). The first FFT used fft4g's twiddles, built with cosf; the round trip of aec3_fft_unittest's FftAndIfft was 0.002 off at 2.6e6 against its 0.001 bound, so the 128-point tables are now built in double precision as OouraFft stores them, and it passes. AEC3's echo state (#240 step 3): libwebrtc's aec_state (NormalUsage for 1, 2 and 8 render and capture channels, ConvergedFilterDelay), erl_estimator, erle_estimator (VerifyErleIncreaseAndHold, VerifyErleTrackingOnOnsets), signal_dependent_erle_estimator, reverb_model_estimator and filter_analyzer (FilterResize) unit tests pass with their signals and bounds; echo_audibility, transparent_mode and subtractor_output_analyzer, which have no libwebrtc unit tests, have behavioural tests derived from the code. AEC3's residual echo suppression (#240 step 4): libwebrtc's moving_average_spectrum, comfort_noise_generator (CorrectLevel), suppression_gain (BasicGainComputation, UpdateStateDependingOnConfig), suppression_filter (ComfortNoiseInUnityGain, SignalSuppression, SignalTransparency, Delay) and residual_echo_estimator (BasicTest for 1, 2 and 4 render and capture channels, ReverbTest) unit tests pass with their signals and bounds; the death tests and the neural estimator's metrics tests don't apply. The two nearend detectors, which have no libwebrtc unit tests, have behavioural tests derived from the code. AEC3 as a whole (#240 step 5): libwebrtc's frame_blocker, block_framer, block_delay_buffer, echo_remover_metrics, echo_remover (BasicApiCalls, BasicEchoRemoval) and block_processor (BasicSetupAndApiCalls, TestLongerCall) unit tests pass with their signals and bounds; EchoCanceller3's pass-through, render queue and saturation tests are derived from echo_canceller3_unittest.cc on the real block processor (the originals mock it). E2E_EchoDelay.Aec3FollowsAudioRouteChangeAsLibwebrtc and E2E_EchoCanceller.Aec3FullDuplexCallAsLibwebrtc check the `apm v2` chain against libwebrtc M157's APM on the same signals (docs/results/apm-webrtc.md) within 1 dB. #240 step 6 moved Aec3Fft from fft4g's rdft to the ported `OouraFft` (fft_size_128): Aec3Filter.OouraFft128MatchesDft checks it against a double-precision DFT, the aec3_fft unit tests still pass, and the e2e ERLE and double-talk numbers stay at libwebrtc's.
