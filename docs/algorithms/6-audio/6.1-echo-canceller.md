# 6.1 Acoustic echo cancellation

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Echo (far-end audio coming back through the mic) -> AEC3 acoustic echo canceller; AECM for mobile

## The issue

On a speakerphone, laptop or conference device, the far end's voice comes out of the loudspeaker, bounces around the room and enters the microphone. Without cancellation the far-end talker hears themselves 100-500 ms later, which makes conversation nearly impossible. At high gain the loop can turn into howling feedback.

The echo is not a simple delayed copy: the room filters it through tens to hundreds of milliseconds of reflections, which change when someone moves. The canceller must learn this response continuously from the signal itself. It must not learn from the local talker's voice when both people speak at once (double talk), or it will cancel the local voice instead. Whatever the linear model cannot capture (loudspeaker distortion, model error) must be suppressed without muting the local talker.

## Design

Linear stage: partitioned-block frequency-domain NLMS (PBFDAF / MDF). Blocks of B = 5 ms, FFT N = next_pow2(2B), P partitions of B taps cover `filter_length_ms` of echo tail after the bulk delay found by EchoDelayEstimator. Each partition's gradient is constrained to B taps (overlap-save), and the step is normalized per frequency bin by the far-end power summed over partitions.

Step size: after initial convergence the NLMS step follows the residual-echo-to-error ratio (Valin 2007), mu = mu0 * min(1, leak * |y|^2 / |e|^2); near-end speech inflates |e|^2, so adaptation nearly stops during double talk without an explicit detector.

Double talk: two filters (Speex MDF style). The background filter always adapts; the foreground filter (which produces the output) receives the background's coefficients only when the background's error-energy improvement is statistically significant: its mean, at two time constants, must exceed a multiple of its variance (estimated from the foreground error energy times the energy of the difference between the two errors). Near-end speech makes that difference noisy, so a background filter disturbed by double talk is not copied; a significantly worse background is reset from the foreground.

Residual echo suppression: the linear filter leaves residual echo (non-linearities, model mismatch). A second STFT stage estimates the residual as leak * |Y(k)|^2, where the leak is the correlation between error and echo-estimate power spectra over time (near speech is uncorrelated with the far end, so double talk does not inflate it), and applies a suppression gain per bin.

```
                      block after the previous one, or zero padding), with
                      AEC3's packing: 65 bins, re/im.
  RenderDelayBuffer   the render blocks, their FFTs and power spectra in
                      rings of 13 + 1 + 5 * 24 + 32 + 1 = 64 / 4 ... blocks
                      (GetRenderDelayBufferSize), read at the delay the
                      delay controller (aec3_delay.h) found, plus the
                      decimated ring the delay estimator reads.
  AdaptiveFirFilter   partitioned-block frequency-domain filter: 64-sample
                      partitions, 12 at the start and 13 after the initial
                      state (about 52 ms), resized over 250 blocks. One
                      partition per block is constrained to 64 causal taps.
  RefinedFilterUpdateGain  NLMS gain mu = H_error / (0.5 H_error X2 +
                      partitions E2), with the filter-error estimate H_error
                      (from 10000) leaking back up by the ERL times 0.005
                      (initial) or 0.00005 when the refined filter beats the
                      coarse one, 0.5 / 0.05 when it doesn't; floor 0.001,
                      ceiling 2; bins under the noise gate 20075344 don't
                      adapt.
  CoarseFilterUpdateGain   mu = 0.9 (initial) or 0.7 over the render power.
  Subtractor          runs both filters on the capture block, rescales the
                      refined filter when its error grows beyond the
                      capture (misadjustment), copies the refined filter
                      into the coarse one after 5 blocks where the coarse
                      one is worse, and holds the refined leakage at the
                      converged rate for 25 blocks after that.
  RenderSignalAnalyzer  masks the update around narrow-band render peaks
                      and stops it when the render excitation is poor.
```

Differences that remain (tools/catalog.py 6.1): the FFT is fft4g's rdft at n = 128 (sm/audio/fft4g.h), because libwebrtc's 128-point Ooura FFT (common_audio/third_party/ooura/fft_size_128) is not in reference/; it is the same algorithm with tables computed instead of stored. The portable C paths, where x86 libwebrtc runs SSE2/AVX2 (same arithmetic, different float summation order). Several render channels are read as channel 0 for the delay estimate (AlignmentMixer's downmix/adaptive selection isn't ported). No data dumps or render-jitter logging. Subtractor takes the capture saturation flag that AecState holds; AecState itself, the residual echo suppression and EchoCanceller3 are #240's next steps, so nothing calls this module in a call yet.

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#6-audio-quality) for the differences from libwebrtc. This is a compact PBFDAF canceller (in the spirit of Speex MDF), not a port of AEC3. Blocks are 5 ms, with 16 partitions (80 ms tail) after bulk-delay alignment by 6.2. AEC3's linear stage (issue #240 step 2, `audio/aec3_filter.h`, for `apm v2`) is a port of libwebrtc M157's `aec3_fft`, the render buffers (`block_buffer`, `spectrum_buffer`, `fft_buffer`, `render_buffer` and the whole `render_delay_buffer`, of which 6.2's low-rate buffer is the decimated half), `adaptive_fir_filter` (partitioned frequency-domain filter, 64-sample partitions, one partition constrained per block), `adaptive_fir_filter_erl`, `render_signal_analyzer`, `refined_filter_update_gain` (NLMS with the filter-error estimate H_error and ERL leakage), `coarse_filter_update_gain` and `subtractor` (refined and coarse filters, misadjustment rescaling, coarse filter reset from the refined one), with EchoCanceller3Config::Filter's defaults: 12 then 13 partitions, leakage 0.005/0.5 then 0.00005/0.05, error floor 0.001 and ceiling 2, noise gate 20075344, coarse rate 0.9 then 0.7, 250-block configuration changes, a 25-block hangover after a coarse filter reset. Remaining differences: the FFT is fft4g's rdft at n = 128 with OouraFft's double-precision tables, because `common_audio/third_party/ooura/fft_size_128` is not in the reference sources; the portable C paths where x86 libwebrtc runs SSE2/AVX2; several render channels feed the delay estimator through channel 0 (AlignmentMixer isn't ported); Subtractor takes AecState's capture saturation flag as an argument. Nothing in a call uses it yet: AecState, the residual echo suppression and EchoCanceller3 are #240's next steps.

```cpp
struct FftData {
  void Assign(const FftData& src) {
    re = src.re;
    im = src.im;
    im[0] = im[kFftLengthBy2] = 0;
  }
  void Clear() {
    re.fill(0.f);
    im.fill(0.f);
  }
  // |X|^2 per bin.
  void Spectrum(std::span<float> power_spectrum) const {
    for (size_t k = 0; k < kFftLengthBy2Plus1; ++k) power_spectrum[k] = re[k] * re[k] + im[k] * im[k];
  }
  void CopyFromPackedArray(const std::array<float, kFftLength>& v);
  void CopyToPackedArray(std::array<float, kFftLength>* v) const;

  std::array<float, kFftLengthBy2Plus1> im{};

// The rings of block_buffer.h, spectrum_buffer.h and fft_buffer.h.
template <typename T>
struct RingBuffer {
  RingBuffer(size_t n, const T& init) : size(static_cast<int>(n)), buffer(n, init) {}
  int IncIndex(int index) const { return index < size - 1 ? index + 1 : 0; }
  int DecIndex(int index) const { return index > 0 ? index - 1 : size - 1; }
  int OffsetIndex(int index, int offset) const { return (size + index + offset) % size; }
  void UpdateWriteIndex(int offset) { write = OffsetIndex(write, offset); }
  void IncWriteIndex() { write = IncIndex(write); }
  void DecWriteIndex() { write = DecIndex(write); }
  void UpdateReadIndex(int offset) { read = OffsetIndex(read, offset); }
  void IncReadIndex() { read = IncIndex(read); }
  void DecReadIndex() { read = DecIndex(read); }
  const int size;
  std::vector<T> buffer;
  int write = 0;
  int read = 0;
};
struct BlockBuffer : RingBuffer<Block> {
  BlockBuffer(size_t n, size_t num_bands, size_t num_channels)
      : RingBuffer(n, Block(static_cast<int>(num_bands), static_cast<int>(num_channels))) {}
};
```

## Verification notes

Several defects were found and fixed. (1) The delay estimate was wrong (see 6.2), which capped ERLE at 12 dB. (2) Double talk corrupted the filter: the background filter partly 'cancels' near speech for a few blocks and was then copied to the foreground. An ERLE-based double-talk detector was tried and rejected (it fired on 40% of far-end-only blocks). The final design uses Speex's statistical copy rule plus Valin's adaptive step size, which collapses during double talk (step 0.35 -> 0.002): near-end SNR went from -4 to +9 dB. (3) After an echo-path change the convergence state was not reset, so the adaptive step stayed near zero and ERLE never recovered (0 dB); it now recovers to 25.6 dB. AEC3's linear stage (#240 step 2): libwebrtc's aec3_fft, render_delay_buffer, adaptive_fir_filter (FilterSize, FilterStatisticsAccess, FilterAndAdapt), coarse_filter_update_gain, refined_filter_update_gain and subtractor unit tests pass with their signals and bounds (multi-channel cases with the debug-build parameters; the SIMD-equivalence and death tests don't apply). The first FFT used fft4g's twiddles, built with cosf; the round trip of aec3_fft_unittest's FftAndIfft was 0.002 off at 2.6e6 against its 0.001 bound, so the 128-point tables are now built in double precision as OouraFft stores them, and it passes.
