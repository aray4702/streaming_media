# 6.9 Audio level (RFC 6464)

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Showing who is talking, and voice activity without decoding -> audio level header extension (RFC 6464)

## The issue

A receiver often wants to know how loud each speaker is, or whether the packet holds speech, without decoding it: for a level meter, or when the audio is encrypted end to end and only the sender can measure it. The sender therefore attaches a one-byte level and voice flag to each packet (the RFC 6464 header extension).

The level has to be computed the same way on every device (RMS in -dBov, 127 for digital silence) and packed into seven bits next to the voice flag, so that any receiver, including libwebrtc, reads it correctly.

## Design

ComputeLevel + extension codec: per-packet level in -dBov (0 = full scale, 127 = silence) plus the voice-activity flag, encoded as the one-byte RFC 6464 header extension value  V(1) | level(7). The receiver can show a level meter or see voice activity without decoding any audio.

The level is libwebrtc's `RmsLevel` (modules/audio_processing/rms_level.cc, #567): `ChannelSend` feeds it every 10 ms capture frame (`AnalyzeMuted` for a frame muted after a muted one) and writes `Average()` into each packet (audio/channel_send.cc:390-393, 913-921), so a 20 ms packet carries the level of both of its frames.

libwebrtc's `RmsLevel` (modules/audio_processing/rms_level.cc): the level behind the RFC 6464 audio-level extension. In core because both the audio section and the RTP send path (`RtpSender`, as `ChannelSend`) use it.

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#6-audio-quality) for the differences from libwebrtc. AudioLevelMeter is libwebrtc's voe::AudioLevel (issue #101): the stats level of a send stream, the maximum absolute sample refreshed every 11th frame and decayed to a quarter, and total energy and duration. The RFC 6464 header level is libwebrtc's RmsLevel (modules/audio_processing/rms_level.cc, issue #567): the mean square over every 10 ms chunk since the last Average(), as -dBov rounded as libwebrtc, 127 for digital silence and 126 for faint non-zero input, restarted when the chunk size changes. As ChannelSend, the send path computes it (issue #567): Session::AnalyzeAudioCapture feeds each 10 ms capture frame to the stream's RmsLevel in RtpSender (AnalyzeMuted for a muted frame after a muted one), and every audio packet carries Average() while the extension is mapped, unless the caller passes a level (the override); the voice bit is off for an Opus DTX frame. Session::ProcessAudioCapture also mutes the frame first as libwebrtc's AudioFrameOperations::Mute (issue #879, sm/core/audio_frame_operations.h): a 128-sample fade-out on the frame where mute starts, zeros while muted, a 128-sample fade-in on the frame where it ends. RmsLevel lives in core (sm/core/rms_level.h) so the RTP section can use it. ComputeLevel is RmsLevel on one frame. 

## Implementation skeleton

Files: [include/sm/audio/audio_level.h](../../../include/sm/audio/audio_level.h), [src/audio/audio_level.cc](../../../src/audio/audio_level.cc), [include/sm/core/rms_level.h](../../../include/sm/core/rms_level.h), [src/core/rms_level.cc](../../../src/core/rms_level.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::audio {

struct AudioLevel {
  uint8_t level = 127;  // -dBov.
  bool voice = false;
};

uint8_t EncodeAudioLevelExtension(const AudioLevel& l);
AudioLevel DecodeAudioLevelExtension(uint8_t byte);

// libwebrtc's `RmsLevel`, in core so the RTP send path can use it (#567).
using RmsLevel = dsp::RmsLevel;

// Level of one frame of normalized samples ([-1, 1]) in -dBov: `RmsLevel` of
// the frame scaled to int16 (full-scale square wave = 0).
uint8_t ComputeLevel(std::span<const float> frame);

// libwebrtc's `voe::AudioLevel` (audio/audio_level.cc): the stats level of a
// send stream. The full-range level is the maximum absolute sample, refreshed
// every 11th frame and decayed to a quarter after each refresh; the total
// energy grows by the energy of that level (not of the frame, crbug 10784)
// times the frame duration. The RFC 6464 header-extension level above is a
// different quantity (libwebrtc takes it from the audio processing RMS).
class AudioLevelMeter {
 public:
  static constexpr int kUpdateFrequency = 10;
  void Reset();
  // `abs_max` is the largest |sample| of the frame in int16 units (0 if muted).
  void ComputeLevel(int16_t abs_max, double duration_s);
  void ComputeLevel(std::span<const int16_t> frame, double duration_s);
  int16_t LevelFullRange() const { return current_level_full_range_; }
  void ResetLevelFullRange();
  double TotalEnergy() const { return total_energy_; }
  double TotalDuration() const { return total_duration_; }

};

}  // namespace sm::audio
```

```cpp
namespace sm::dsp {

// libwebrtc's `RmsLevel` (RFC 6465): accumulates the mean square of int16
// samples over the chunks passed since the last `Average()`, as -dBov in
// [0, 127]. 127 is digital silence; a faint but non-zero input reads 126.
// A chunk of a different size than the last one restarts the measurement.
class RmsLevel {
 public:
  struct Levels {
    int average;
    int peak;
  };
  static constexpr int kMinLevelDb = 127;
  static constexpr int kInaudibleButNotMuted = 126;

  RmsLevel() { Reset(); }
  void Reset();
  void Analyze(std::span<const int16_t> data);
  // Samples in int16 range (not normalized), truncated to int16 as libwebrtc.
  void Analyze(std::span<const float> data);
  // A chunk of `length` zero samples.
  void AnalyzeMuted(size_t length);
  // The level since the last call; resets the measurement.
  int Average();
  // Also the peak: the loudest chunk's level. Resets the measurement.
  Levels AverageAndPeak();

};

}  // namespace sm::dsp
```

## Metrics and observability

Every class implements `MetricsSource::ExportMetrics`, so it can be registered in a `MetricsRegistry` and exported as JSON or Prometheus text. Histograms expand to `.count/.mean/.p50/.p95/.p99/.max`.

## Test methods

**Unit tests** (deterministic, no network):

- `AudioLevel`: `ExtensionAndLevel`, `ActiveSpeakerHysteresis`
- `RmsLevel`: (not run)

**End-to-end test** (sender -> simulated network -> receiver, `tests/e2e/`):

- `E2E_AudioLevel`: `ActiveSpeakerFollowsTurns`

Level and voice flag are encoded into the RFC 6464 byte and decoded again; the level of known tones and silence must match.

## Verification notes

RmsLevel (issue #567) is checked against libwebrtc's own RmsLevel on 400 packets and the extension byte against libwebrtc's AudioLevelExtension in both directions (sm_rtcp_interop).
