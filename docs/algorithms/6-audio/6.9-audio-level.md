# 6.9 Audio level (RFC 6464) and active speaker detection

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Detecting who's talking -> audio level header extension (RFC 6464), voice activity

## The issue

An SFU in a group call has to pick who is speaking (for the "active speaker" layout, for forwarding only the relevant audio, for picking which video to send at high quality). It forwards encrypted audio and cannot decode it. The sender therefore attaches a one-byte level and voice flag to each packet.

Choosing the speaker from these levels is still subtle. Levels fluctuate every packet, people interject briefly, cough or laugh, and background noise has a level too. A naive "loudest now" choice makes the layout jump around constantly.

## Design

ComputeLevel + extension codec: per-packet level in -dBov (0 = full scale, 127 = silence) plus the voice-activity flag, encoded as the one-byte RFC 6464 header extension value  V(1) | level(7). An SFU can then pick speakers without decoding any audio.

ActiveSpeakerDetector: consumes (stream, level, voice) observations, keeps a speech-activity score per stream (exponentially smoothed, voiced loud frames score high), and switches the dominant speaker only when a challenger beats the current speaker by `switch_margin` for `switch_hold`, so short interjections or coughs do not flip the layout.

## Implementation skeleton

Files: [include/sm/audio/audio_level.h](../../../include/sm/audio/audio_level.h), [src/audio/audio_level.cc](../../../src/audio/audio_level.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::audio {

struct AudioLevel {
  uint8_t level = 127;  // -dBov.
  bool voice = false;
};

uint8_t EncodeAudioLevelExtension(const AudioLevel& l);
AudioLevel DecodeAudioLevelExtension(uint8_t byte);
// RMS level of a frame in -dBov (full-scale square wave = 0).
uint8_t ComputeLevel(std::span<const float> frame);

struct ActiveSpeakerConfig {
  double smoothing = 0.15;      // Per observation (10-20 ms).
  double switch_margin = 1.3;   // Challenger score / current score.
  TimeDelta switch_hold = TimeDelta::Millis(600);
  int silence_level = 70;       // -dBov at or below which a frame is ignored.
};

class ActiveSpeakerDetector : public MetricsSource {
 public:
  explicit ActiveSpeakerDetector(ActiveSpeakerConfig cfg = {}) : cfg_(cfg) {}
  void OnLevel(uint32_t stream, const AudioLevel& l, Timestamp now);
  std::optional<uint32_t> dominant() const { return dominant_; }
  uint64_t switches() const { return switches_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::audio
```

## Test methods

**Unit tests** (deterministic, no network):

- `AudioLevel`: `ExtensionAndLevel`, `ActiveSpeakerHysteresis`

**End-to-end test** (sender -> simulated network -> receiver, `tests/e2e/`):

- `E2E_AudioLevel`: `ActiveSpeakerFollowsTurns`

Four participants take 5 s turns over background noise; the SFU sees only the RFC 6464 byte per 20 ms packet. Dominant-speaker accuracy (from 1.5 s into each turn) and switch count.
