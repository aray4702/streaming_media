# 6.10 Audio mixer (loudest N)

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Mixing several remote speakers -> audio mixer that picks the loudest N speakers

## The issue

A mixing server or device must combine many participants' audio into one stream. Summing everyone adds every participant's background noise: with 20 people, the noise floor rises by 13 dB. The sum of several loud speakers also exceeds full scale and clips. Selecting only the loudest few is better, but switching a participant in or out abruptly causes clicks. Re-ranking every 10 ms makes similar-level speakers swap constantly.

## Design

Each 10 ms the mixer ranks sources by smoothed energy, mixes only the loudest `max_mixed` (others would only add noise), ramps a source's gain up or down across one frame when it enters or leaves the mix so there is no click, and runs the sum through a limiter so it never clips. A selected source keeps its slot until a challenger is clearly louder (hysteresis), which avoids rapid swapping between similar speakers.

## Implementation skeleton

Files: [include/sm/audio/mixer.h](../../../include/sm/audio/mixer.h), [src/audio/mixer.cc](../../../src/audio/mixer.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::audio {

struct MixerConfig {
  int sample_rate = 16000;
  size_t max_mixed = 3;
  double energy_smoothing = 0.3;
  double hysteresis = 1.5;  // Energy ratio needed to take a mixed slot.
  LimiterConfig limiter;
};

class AudioMixer : public MetricsSource {
 public:
  explicit AudioMixer(MixerConfig cfg = {});
  // Frames for this 10 ms tick; all spans must have the same length.
  void Mix(const std::map<uint32_t, std::span<const float>>& sources, std::span<float> out);
  const std::vector<uint32_t>& mixed() const { return mixed_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::audio
```
