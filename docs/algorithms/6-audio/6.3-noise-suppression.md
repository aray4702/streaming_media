# 6.3 Noise suppression

Section 6, *Audio quality (APM)*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Background noise -> NS noise suppression (RNNoise-style ML in some builds)

## The issue

Microphones pick up fans, traffic, keyboards, cafes and car noise. The noise masks speech, tires listeners, and wastes bitrate because the encoder spends bits coding noise faithfully. The noise overlaps speech in frequency, so a fixed filter cannot remove it.

Suppression must estimate the noise spectrum while people are talking, from moments and frequencies where speech is absent, and attenuate each frequency according to how much speech it contains at that moment. Doing this crudely produces "musical noise" (random warbling tones) or muffles and chops the speech, which can sound worse than the original noise.

## Design

10 ms hop, 20 ms sqrt-Hann analysis/synthesis windows (50% overlap, perfect reconstruction), zero-padded FFT. Per frequency bin: - noise PSD: minimum-tracking of the smoothed power spectrum (follows

```
   drops immediately, rises at most `noise_rise_db_per_s`), with a
   speech-presence gate so speech does not leak into the estimate;
```

- a-priori SNR, decision-directed (Ephraim-Malah):

```
       xi = a * G_prev^2 * |X_prev|^2 / N + (1 - a) * max(gamma - 1, 0)
```

- Wiener gain G = xi / (1 + xi), floored at -`max_attenuation_db`. Algorithmic latency: one hop (10 ms).

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#6-audio-quality) for the differences from libwebrtc. Classic statistical NS (Wiener + decision-directed SNR); an ML suppressor (RNNoise) could be plugged into the same 10 ms interface.

## Implementation skeleton

Files: [include/sm/audio/noise_suppressor.h](../../../include/sm/audio/noise_suppressor.h), [src/audio/noise_suppressor.cc](../../../src/audio/noise_suppressor.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::audio {

struct NoiseSuppressorConfig {
  int sample_rate = 16000;
  float max_attenuation_db = 18.0f;  // "moderate"; 12 low, 24 very high.
  float dd_alpha = 0.98f;
  float noise_rise_db_per_s = 4.0f;
  float psd_smoothing = 0.7f;
};

struct NoiseSuppressorStats {
  uint64_t frames = 0;
  float last_mean_gain_db = 0;
  float noise_level_dbfs = 0;
  Histogram gain_db;
};

class NoiseSuppressor : public MetricsSource {
 public:
  explicit NoiseSuppressor(NoiseSuppressorConfig cfg = {});
  // In-place on a 10 ms frame. Output is delayed by latency_samples().
  void Process(std::span<float> frame);
  size_t latency_samples() const { return hop_; }
  const NoiseSuppressorStats& stats() const { return stats_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::audio
```

## Metrics and observability

Every class implements `MetricsSource::ExportMetrics`, so it can be registered in a `MetricsRegistry` and exported as JSON or Prometheus text. Histograms expand to `.count/.mean/.p50/.p95/.p99/.max`.

## Test methods

**Unit tests** (deterministic, no network):

- `NoiseSuppressor`: `AttenuatesStationaryNoise`, `ImprovesSnr`

**End-to-end test** (sender -> simulated network -> receiver, `tests/e2e/`):

- `E2E_NoiseSuppressor`: `ImprovesSnrInChain`

Near-end speech in white noise at about 7 dB SNR through HPF -> NS; SNR against the clean talker (passed through the same HPF) before and after.

## Benchmarks

Throughput benchmarks have a speed budget (ns per item, or a minimum real-time factor for media processing); quality benchmarks rerun an end-to-end scenario and gate its outcome. A benchmark passes only if every requirement holds.

| Benchmark | Requirement | macOS arm64 (native) | WebAssembly (Node) |
|---|---|---|---|
| `audio/NoiseSuppressor_10ms` | realtime_factor >= 300 | PASS: 3.52 us/frame, 2838x real time | PASS: 4.85 us/frame, 2063x real time |

## Verification notes

The first chain test measured SNR against the raw talker, so the HPF's low-frequency phase shift counted as noise; the reference now goes through the same HPF. NS raises SNR from 7.6 to 12.9 dB.
