# 1.2 Ports and candidates

Section 1, *Connectivity*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Describing where a peer can be reached -> host, server-reflexive and relay candidates on UDP ports

## The issue

A peer must tell the other where it can be reached, and the answer depends on the network: its own interface addresses (host), the address a NAT shows to the outside (server-reflexive) and an address on a relay server. Each address is a candidate with a priority, foundation and type that the other side uses to order its attempts.

Getting the details wrong, such as the priority formula, the address family or which network an address belongs to, makes two correct peers pick bad pairs or none.

## Design

ICE candidates (issue #999, part of ICE #990, milestone 3): libwebrtc M157's api/candidate.{h,cc} (compare/webrtc/reference/api/).

A Candidate is one transport address an ICE agent offers: its type (host, server-reflexive, peer-reflexive, relay), priority, foundation, related address, generation, network id and cost. The priority follows RFC 5245 4.1.2.1 with libwebrtc's local preference ((network preference << 8 | RFC 3484 address precedence) + relay preference); the foundation is libwebrtc's keyed hash: HMAC-SHA256, under a random key that never leaves the process, of the type, the base IP, the protocols and the ICE tie-breaker, so a hidden base address can't be recovered from it.

A hostname (mDNS) address is kept as libwebrtc keeps it (#1152): the parser sets it with SetIP (a name that is not an IP literal leaves the IP unspecified), the candidate-attribute writes the name when there is no IP, and ToSanitizedCopy hides an address behind its name.

Differences from libwebrtc: - No DTLS fingerprint on the candidate and no network slice. The parser

```
  (ParseCandidateString, #1062) checks a TLS candidate's fingerprint
  extension as libwebrtc does but doesn't keep it.
```

- The foundation's HMAC-SHA256 and the random bytes for ids and the key

```
  come from the STUN crypto hooks (sm/p2p/stun.h, SetStunCrypto). Without
  them the foundation is a CRC-32 of the same input under a fixed key and
  ids come from a fixed-seed generator: tests only, as for transaction ids.
```

IP and socket addresses (issue #996, part of ICE #990, milestone 3).

libwebrtc's rtc_base/ip_address.{h,cc} and rtc_base/socket_address.{h,cc} at M157 (compare/webrtc/reference/rtc_base/), the parts the p2p layer uses: IPv4 and IPv6 addresses ordered and compared as libwebrtc does, the address classes ICE looks at (any, loopback, link-local, private, shared), parsing and printing. A hostname is kept as libwebrtc keeps it (SetIP with a name, SetResolvedIP, IsUnresolvedIP, and the name in comparisons of addresses without an IP), for mDNS candidates (#1152); the library resolves nothing itself: the ICE agent asks an AsyncDnsResolverFactoryInterface the host provides (sm/p2p/async_dns_resolver.h).

No socket API is used, so it builds on every platform, wasm included.

The network interface an ICE port gathers on (issue #999, part of ICE #990, milestone 3): the parts of libwebrtc M157's rtc_base/network.{h,cc} and rtc_base/network_constants.h (compare/webrtc/reference/rtc_base/) that a Port reads: the adapter type and its network cost, the preference the network manager gives it, its id, its addresses and the best one to bind.

The network list a port allocator reads is NetworkManager's (sm/p2p/network_manager.h, #1001); enumerating the host's interfaces is an OS network monitor's job (C11, C12). A test or the emulated network builds a Network directly or through StaticNetworkManager. Field trials are at libwebrtc's defaults (all off): WebRTC-UseDifferentiatedCellularCosts, WebRTC-AddNetworkCostToVpn and WebRTC-UnifiedCommunications (network slices) are not ported.

ICE ports (issue #999, part of ICE #990, milestone 3): libwebrtc M157's p2p/base/port.{h,cc} and port_interface.h (compare/webrtc/reference/ p2p/base/).

A Port gathers the candidates of one transport (UDP, TCP or a relay) on one network interface and answers the STUN traffic that reaches it from addresses it has no connection to: - AddAddress makes a candidate with libwebrtc's priority (type preference,

```
  network preference, RFC 3484 address precedence, component) and
  foundation, and signals it (candidate ready, then port complete when
  final).
```

- CreateConnection makes a Connection (#1000, sm/p2p/connection.h) to a remote candidate; the port owns its

```
  connections, one per remote address, hands them the packets from their address, and deletes them on
  DestroyConnection (now) or DestroyConnectionAsync (at the next Process, where libwebrtc posts the delete).
```

- Incoming STUN is checked as Port::GetStunMessage does: a binding request

```
  without USERNAME or MESSAGE-INTEGRITY gets 400, a wrong local ufrag or a
  bad MESSAGE-INTEGRITY 401, unknown comprehension-required attributes 420
  with UNKNOWN-ATTRIBUTES. A good request from an unknown address raises
  the unknown-address signal, which creates a peer-reflexive candidate and
  a connection (#1000), then the ICE role check: a conflicting role answers
  487 or raises the role-conflict signal, by tie-breaker (RFC 5245 7.2.1.1).
  A GOOG-PING to an address without a connection gets 400.
```

- A port no ICE agent keeps (KeepAliveUntilPruned) is destroyed

```
  kPortTimeoutDelay (STUN_TOTAL_TIMEOUT + 5 s) after it was made or after
  its last connection went, or as soon as it is pruned, once it has no
  connections.
```

The library's time model replaces libwebrtc's network thread: nothing reads a clock or posts a task. Calls that may send take `now`; the owner calls Process(now) at NextProcessTime(). libwebrtc's port deletes itself when it dies; here it marks itself dead (dead()) and raises the destroyed signal, and the owner (the allocator, #1001) deletes it.

The owner also runs the connections' STUN transactions through Process(now). TURN ports are in sm/p2p/turn_port.h (#1031), TCP ports in sm/p2p/tcp_port.h (#1151). Not here: mDNS name registration and the local network access permission (Chromium's; with no permission factory libwebrtc grants every address, as here).

UDP and STUN ports (issue #999, part of ICE #990, milestone 3): libwebrtc M157's p2p/base/stun_port.{h,cc} (compare/webrtc/reference/p2p/base/).

A UDPPort binds one UDP socket on its network (or shares the allocator's) and gathers a host candidate for the socket's address, then a server-reflexive candidate from each STUN server (STUN binding requests, RFC 5389). A StunPort gathers only the server-reflexive candidates. As in libwebrtc: - Binding requests use STUN's retransmission schedule (stun_request.h);

```
  after a response the port sends the next one kStunKeepaliveInterval
  (10 s, or the configured interval) later to keep the NAT binding open,
  for as long as the keepalive lifetime allows: forever, or 2 minutes on a
  high-cost (cellular) network. After an error response it retries on the
  same interval for up to 50 s.
```

- A server that times out, answers with an error or has an incompatible

```
  address family counts as done; the port is complete when every server
  is done and at least one answered (or there were none, or the socket is
  shared), and fails otherwise. Errors are signalled with the server's URL.
```

- A shared socket's reflexive address equal to its local address adds no

```
  candidate (the host candidate covers it), nor does an address another
  server already gave.
```

Differences from libwebrtc: STUN servers are given by IP address (no DNS resolution: the library's addresses carry no hostnames), there is no mDNS obfuscation and no local network access permission (granted, as with no permission factory). The reflexive candidate's URL is "stun:<ip>:<port>", as libwebrtc writes it for a server configured by its IP literal (which becomes the address's hostname there).

libwebrtc M157 counterpart: `api/candidate.{h,cc}`, `rtc_base/{socket_address,ip_address,network}.{h,cc}`, `p2p/base/{port,stun_port}.{h,cc}`, `p2p/client/basic_port_allocator` (the port classes only). Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.3](../../design/libwebrtc-parity.md#103-ports-and-candidates-srcp2pcandidatenetworkportstun_portcc-c3-part-3-999). Requirement C3 part 3. A `UDPPort` gathers a host candidate; a `StunPort` also asks the STUN server for its server-reflexive address and checks the answer against libwebrtc's address-family and priority rules.

namespace sm::p2p {

// AF_UNSPEC / AF_INET / AF_INET6 without the socket headers.
enum class IpFamily : uint8_t { kUnspec, kV4, kV6 };

class IpAddress {
 public:
  IpAddress() = default;  // AF_UNSPEC, as IPAddress().
  // IPv4 in host byte order, as IPAddress(uint32_t).
  explicit IpAddress(uint32_t v4_host_order) : family_(IpFamily::kV4), v4_(v4_host_order) {}
  static IpAddress V4(uint8_t a, uint8_t b, uint8_t c, uint8_t d) {
    return IpAddress((uint32_t{a} << 24) | (uint32_t{b} << 16) | (uint32_t{c} << 8) | uint32_t{d});
  }
  static IpAddress V6(const std::array<uint8_t, 16>& bytes) {
    IpAddress ip;
    ip.family_ = IpFamily::kV6;
    ip.v6_ = bytes;
    return ip;
  }
  // IPFromString: dotted IPv4 or RFC 4291 IPv6 text (with "::" and an
  // embedded IPv4 tail). nullopt when it is neither.
  static std::optional<IpAddress> FromString(std::string_view s);

  IpFamily family() const { return family_; }
  // v4AddressAsHostOrderInteger: 0 for anything that isn't IPv4.
  uint32_t v4() const { return family_ == IpFamily::kV4 ? v4_ : 0; }
  // ipv6_address(): zero for anything that isn't IPv6.
  const std::array<uint8_t, 16>& v6() const { return v6_; }
  // Size of the address in bytes: 4, 16, or 0 when unspecified.
  size_t Size() const { return family_ == IpFamily::kV4 ? 4 : family_ == IpFamily::kV6 ? 16 : 0; }
  // overhead(): the IP header's size, 20 bytes for IPv4 and 40 for IPv6.
  int overhead() const { return family_ == IpFamily::kV4 ? 20 : family_ == IpFamily::kV6 ? 40 : 0; }

  // inet_ntop's text: dotted IPv4; IPv6 with the longest run of two or more
  // zero groups as "::" (RFC 5952), and IPv4-mapped as ::ffff:a.b.c.d. Empty
  // for AF_UNSPEC.
  std::string ToString() const;
  // The last IPv4 byte or the last five IPv6 groups hidden, as libwebrtc logs.
  std::string ToSensitiveString() const;

  // Normalized(): an IPv4-mapped IPv6 address becomes the IPv4 address.
  IpAddress Normalized() const;
  // NormalizeWithCheckForEmbeddedIPv4Address(): also IPv4-compatible
  // (::a.b.c.d) and 6to4 (2002:a.b.c.d::/48) addresses.
  IpAddress NormalizeWithCheckForEmbeddedIPv4Address() const;
  // AsIPv6Address(): an IPv4 address as IPv4-mapped IPv6.
  IpAddress AsIPv6Address() const;

  friend bool operator==(const IpAddress& a, const IpAddress& b);
  friend bool operator!=(const IpAddress& a, const IpAddress& b) { return !(a == b); }
  // IPv4 sorts before IPv6; then by value (IPAddress::operator<).
  friend bool operator<(const IpAddress& a, const IpAddress& b);

};

class SocketAddress {
 public:
  SocketAddress() = default;  // Nil.
  SocketAddress(const IpAddress& ip, uint16_t port) : ip_(ip), port_(port) {}
  SocketAddress(uint32_t v4_host_order, uint16_t port) : ip_(v4_host_order), port_(port) {}
  // SocketAddress(hostname, port): SetIP(hostname), so an IP literal gives that IP and any other name an unresolved
  // address (no IP, the name kept).
  SocketAddress(std::string_view hostname, uint16_t port) : port_(port) { SetIP(hostname); }
  // Parses "a.b.c.d:port" and "[v6]:port" (FromString). nullopt otherwise.
  static std::optional<SocketAddress> FromString(std::string_view s);

  const IpAddress& ipaddr() const { return ip_; }
  uint32_t ip() const { return ip_.v4(); }
  IpFamily family() const { return ip_.family(); }
  uint16_t port() const { return port_; }
  void SetIp(const IpAddress& ip) { ip_ = ip; }
  // SetIP(hostname): an IP literal sets the IP (and is kept as the name); any other name leaves the IP unspecified.
  void SetIP(std::string_view hostname);
  // SetResolvedIP: the IP a name resolved to; the name is kept.
  void SetResolvedIP(const IpAddress& ip) { ip_ = ip; }
  void SetPort(uint16_t port) { port_ = port; }
  // The name the address was given by, if any (SocketAddress::hostname): an mDNS candidate's name (#1152), and
  // TLS's SNI and the name the server's certificate must match (#1035).
  const std::string& hostname() const { return hostname_; }
  // Sets the name and keeps the IP (the library's own: a TLS server's name beside its resolved IP).
  void SetHostname(std::string hostname) {
    hostname_ = std::move(hostname);
    literal_ = IpAddress::FromString(hostname_).has_value();
  }
  // A name that is not an IP literal and has no IP yet (an mDNS candidate before it is resolved).
  bool IsUnresolvedIP() const { return IpIsUnspec(ip_) && !literal_ && !hostname_.empty(); }

  // No name, no IP and no port.
  bool IsNil() const { return hostname_.empty() && IpIsUnspec(ip_) && port_ == 0; }
  // A usable IP and a port.
  bool IsComplete() const { return !IpIsAny(ip_) && !IpIsUnspec(ip_) && port_ != 0; }
  bool IsAnyIp() const { return IpIsAny(ip_); }
  bool IsLoopbackIp() const { return IpIsLoopback(ip_); }
  bool IsPrivateIp() const { return IpIsPrivate(ip_); }

  // The name if the address has one that is not an IP literal, else "a.b.c.d" or "[v6]" (HostAsURIString).
  std::string HostAsURIString() const;
  std::string HostAsSensitiveURIString() const;
  // HostAsURIString() + ":port".
  std::string ToString() const;
  std::string ToSensitiveString() const;

  // The IPs are equal, and so are the names when there is no usable IP (any or unspecified), as libwebrtc's EqualIPs.
  bool EqualIps(const SocketAddress& o) const {
    return ip_ == o.ip_ && ((!IpIsAny(ip_) && !IpIsUnspec(ip_)) || hostname_ == o.hostname_);
  }
  bool EqualPorts(const SocketAddress& o) const { return port_ == o.port_; }
  friend bool operator==(const SocketAddress& a, const SocketAddress& b) { return a.EqualIps(b) && a.EqualPorts(b); }
  friend bool operator!=(const SocketAddress& a, const SocketAddress& b) { return !(a == b); }
  // By IP, then by name when neither has a usable IP, then by port.
  friend bool operator<(const SocketAddress& a, const SocketAddress& b) {
    if (a.ip_ != b.ip_) return a.ip_ < b.ip_;
    if ((IpIsAny(a.ip_) || IpIsUnspec(a.ip_)) && a.hostname_ != b.hostname_) return a.hostname_ < b.hostname_;
    return a.port_ < b.port_;
  }

};

}  // namespace sm::p2p

class PortCallbacks {
 public:
  void Add(const void* tag, std::function<void(Args...)> cb) { cbs_.emplace_back(tag, std::move(cb)); }

    std::erase_if(cbs_, [tag](const auto& e) { return e.first == tag; });
