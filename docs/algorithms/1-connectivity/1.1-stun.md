# 1.1 STUN messages

Section 1, *Connectivity*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Finding a path between two peers -> STUN: binding requests and responses, MESSAGE-INTEGRITY and FINGERPRINT

## The issue

Two peers behind NATs know nothing about each other's addresses. STUN is the small request/response protocol that tells a host its address as a server sees it and that carries every connectivity check. Messages must be parsed exactly, because a mistaken attribute length or a wrong integrity check makes a working path look dead, and because STUN is read from the open network, a parser bug is an attack surface.

MESSAGE-INTEGRITY and FINGERPRINT need HMAC-SHA1 and CRC-32, and a request needs a transaction id nobody can guess, so the protocol depends on the TLS library's cryptography.

## Design

STUN messages (RFC 5389 / 8489) and their TURN (RFC 5766) and ICE (RFC 5245) attributes: a port of libwebrtc M157's api/transport/stun.{h,cc} (compare/webrtc/reference/api/transport/), requirement C2 of milestone 3 (#944, #986). The names, constants, wire layout, parsing rules, length limits, MESSAGE-INTEGRITY, GOOG-MESSAGE-INTEGRITY-32 and FINGERPRINT follow that file; M157 has no MESSAGE-INTEGRITY-SHA256.

Crypto is not in this library. HMAC-SHA1 (MESSAGE-INTEGRITY), MD5 (the long-term credential key) and the random bytes for transaction ids come from functions the application installs once with SetStunCrypto() (the window wires BoringSSL's in #984). Without them, signing and checking integrity fail (return false / kIntegrityBad), ComputeStunCredentialHash fails, and GenerateTransactionId falls back to a fixed-seed generator that is NOT unpredictable, which is fine for tests and wrong for a real call.

Differences from libwebrtc, all where libwebrtc would crash or read the wrong type: - AddAttribute() on a signed message returns false and drops the attribute,

```
  and RemoveAttribute() of a non-integrity attribute from a signed message
  returns nullptr, where libwebrtc's RTC_CHECK aborts.
```

- The typed getters (GetUInt32, GetAddress, ...) return nullptr when the

```
  attribute of that type holds another value type (an unknown attribute in
  the designated-expert range is read as a byte string), where libwebrtc's
  static_cast reads it as the wrong class.
```

- The integrity histograms (WebRTC.Stun.Integrity.*) are not kept.

STUN transactions (issue #997, part of ICE #990, milestone 3): libwebrtc M157's p2p/base/stun_request.{h,cc} (compare/webrtc/reference/p2p/base/).

A StunRequest is one outstanding request; the StunRequestManager keeps them by transaction id, retransmits them on libwebrtc's schedule and matches responses to them: - first send after the given delay, then resends 250, 500, 1000, 2000,

```
  4000, 8000, 8000 and 8000 ms apart (STUN_INITIAL_RTO = 250 ms doubling,
  capped at STUN_MAX_RTO = 8000 ms), 9 sends in all
  (STUN_MAX_RETRANSMISSIONS = 8), and the timeout 8000 ms after the last
  send: 39750 ms after the first (STUN_TOTAL_TIMEOUT);
```

- a response is checked as CheckResponse does: by transaction id, then

```
  MESSAGE-INTEGRITY with the request's password when the request requires
  authentication (revalidated if it was checked with another password),
  unauthenticated TURN responses refused except 401 and 300 errors, and a
  response with unknown comprehension-required attributes discarded and the
  transaction failed (RFC 5389 7.3.3 and 7.3.4).
```

The library's time model replaces libwebrtc's task queue: nothing reads a clock or posts a task. The manager's owner passes `now` in and calls Process(now) at NextProcessTime(); the request callbacks get `now`.

Transaction ids guard against spoofed responses (RFC 5389 section 6), so they must be unpredictable on a real call. The manager refuses to send a request while STUN's random-bytes hook is not installed (sm/p2p/stun.h, SetStunCrypto; InstallStunCryptoFromTls() in sm/p2p/stun_crypto_tls.h installs BoringSSL's), unless a test allows the fixed-seed fallback.

STUN's crypto hooks (sm/p2p/stun.h) on sm::tls (#997): HMAC-SHA1 for MESSAGE-INTEGRITY, MD5 for the long-term credential key, and BoringSSL's random bytes for transaction ids, as libwebrtc's stun.cc gets them from rtc_base/message_digest and crypto_random. In the sm::p2p_tls library, built when SM_WITH_TLS is on.

A STUN server for tests (issue #997): libwebrtc M157's p2p/test/stun_server.{h,cc} (compare/webrtc/reference/p2p/test/). It answers binding requests on one packet socket with the address each came from: XOR-MAPPED-ADDRESS, or MAPPED-ADDRESS for an RFC 3489 request without the magic cookie. Other requests get error 600 "Operation Not Supported", and datagrams that don't parse are dropped. On the emulated network it runs on an `EmulatedSocketServer` socket; ICE's STUN ports learn their server-reflexive address from it.

libwebrtc M157 counterpart: `api/transport/stun.{h,cc}`, `p2p/base/stun_request.{h,cc}`, `p2p/test/stun_server.{h,cc}`. Differences from libwebrtc: [libwebrtc parity inventory](../../design/libwebrtc-parity.md), section [10.1](../../design/libwebrtc-parity.md#101-stun-messages-srcp2pstuncc-c2-986). Requirement C2. HMAC-SHA1 and CRC-32 come from sm::tls through `InstallStunCryptoFromTls` (C1).

// ---------------------------------------------------------------- crypto hooks
struct StunCrypto {
  // HMAC-SHA1(key, data) into out[0..20). Returns false on failure.
  bool (*hmac_sha1)(std::span<const uint8_t> key, std::span<const uint8_t> data, uint8_t out[20]) = nullptr;
  // MD5(data) into out[0..16). Returns false on failure.
  bool (*md5)(std::span<const uint8_t> data, uint8_t out[16]) = nullptr;
  // Fills `out` with cryptographically random bytes. Returns false on failure.
  bool (*random_bytes)(std::span<uint8_t> out) = nullptr;
  // HMAC-SHA256(key, data) into out[0..32). Returns false on failure. ICE's
  // candidate foundations use it (Candidate::ComputeFoundation, #999).
  bool (*hmac_sha256)(std::span<const uint8_t> key, std::span<const uint8_t> data, uint8_t out[32]) = nullptr;

// A STUN/TURN message: a type and attributes, each parsed into the class of its
// value type.
class StunMessage {
 public:
  // An invalid type and an empty, legacy (16-byte, RFC 3489) transaction id.
  StunMessage();
  // `type` with a new 12-byte (RFC 5389) transaction id.
  explicit StunMessage(uint16_t type);
  // `transaction_id` must be 12 or 16 bytes.
  StunMessage(uint16_t type, std::string_view transaction_id);
  virtual ~StunMessage();
  StunMessage(const StunMessage&) = delete;
  StunMessage& operator=(const StunMessage&) = delete;

  enum class IntegrityStatus {
    kNotSet = 0,
    kNoIntegrity = 1,   // No MESSAGE-INTEGRITY attribute.
    kIntegrityOk = 2,   // MESSAGE-INTEGRITY checked OK.
    kIntegrityBad = 3,  // MESSAGE-INTEGRITY verification failed.
    kMaxValue = kIntegrityBad,
  };

  int type() const { return type_; }
  size_t length() const { return length_; }
  const std::string& transaction_id() const { return transaction_id_; }
  uint32_t reduced_transaction_id() const { return reduced_transaction_id_; }

  // True for an RFC 3489 message (16-byte transaction id, no magic cookie).
  bool IsLegacy() const;

  // Attribute types in the comprehension-required range that were not recognized.
  std::vector<uint16_t> GetNonComprehendedAttributes() const;

  // The first attribute of `type`, or nullptr. GetAddress(MAPPED_ADDRESS)
  // falls back to XOR-MAPPED-ADDRESS.
  const StunAddressAttribute* GetAddress(int type) const;
  const StunUInt32Attribute* GetUInt32(int type) const;
  const StunUInt64Attribute* GetUInt64(int type) const;
  const StunByteStringAttribute* GetByteString(int type) const;
  const StunUInt16ListAttribute* GetUInt16List(int type) const;
  const StunErrorCodeAttribute* GetErrorCode() const;
  // The ERROR-CODE value, or STUN_ERROR_GLOBAL_FAILURE without one.
  int GetErrorCodeValue() const;
  const StunUInt16ListAttribute* GetUnknownAttributes() const;

  // Takes ownership of `attr` and appends it. Returns false (and drops it) for
  // anything but an integrity or FINGERPRINT attribute once the message is signed.
  bool AddAttribute(std::unique_ptr<StunAttribute> attr);
  // Removes the last attribute of `type`; nullptr if none (or if the message is
  // signed and `type` is not an integrity attribute).
  std::unique_ptr<StunAttribute> RemoveAttribute(int type);
  void ClearAttributes();

  // Checks MESSAGE-INTEGRITY (or GOOG-MESSAGE-INTEGRITY-32) against the bytes
  // Read() parsed. Done once; RevalidateMessageIntegrity() checks again.
  IntegrityStatus ValidateMessageIntegrity(const std::string& password);
  IntegrityStatus RevalidateMessageIntegrity(const std::string& password);
  IntegrityStatus integrity() const { return integrity_; }
  bool IntegrityOk() const { return integrity_ == IntegrityStatus::kIntegrityOk; }
  // The password used to sign or check the message.
  const std::string& password() const { return password_; }

  // Appends a MESSAGE-INTEGRITY / GOOG-MESSAGE-INTEGRITY-32 valid for the message so far.
  bool AddMessageIntegrity(std::string_view password);
  bool AddMessageIntegrity32(std::string_view password);

  // True if `data` has the magic cookie and its method is one of `methods`
  // (FINGERPRINT is not checked).
  static bool IsStunMethod(std::span<const int> methods, std::span<const uint8_t> data);
  // True if `data` is STUN with a correct FINGERPRINT (RFC 5389 7.3, 15.5).
  static bool ValidateFingerprint(std::span<const uint8_t> data);
  // A new 12-byte transaction id from GetStunCrypto().random_bytes.
  static std::string GenerateTransactionId();

  // Appends a FINGERPRINT valid for the message so far.
  bool AddFingerprint();

  // Parses a STUN packet. False if it is not one or is malformed; unknown
  // attributes outside the designated-expert ranges are skipped.
  bool Read(ByteBufferReader* buf);
  bool Write(ByteBufferWriter* buf) const;

  virtual StunMessage* CreateNew() const;

  void SetStunMagicCookie(uint32_t val);
  void SetTransactionIdForTesting(std::string_view transaction_id);

  std::unique_ptr<StunMessage> Clone() const;

  // True if every attribute for which `attribute_type_mask` is true is in both
  // messages with the same encoding.
  bool EqualAttributes(const StunMessage* other, const std::function<bool(int type)>& attribute_type_mask) const;

  static bool ValidateMessageIntegrityForTesting(const std::string& password, std::span<const uint8_t> data);
  static bool ValidateMessageIntegrity32ForTesting(const std::string& password, std::span<const uint8_t> data);

 protected:
  virtual StunAttributeValueType GetAttributeValueType(int type) const;

  std::vector<std::unique_ptr<StunAttribute>> attrs_;

};

// An Internet address.
class StunAddressAttribute : public StunAttribute {
 public:
  static const uint16_t SIZE_UNDEF = 0;
  static const uint16_t SIZE_IP4 = 8;
  static const uint16_t SIZE_IP6 = 20;
  StunAddressAttribute(uint16_t type, const SocketAddress& addr);
  StunAddressAttribute(uint16_t type, uint16_t length);

  StunAttributeValueType value_type() const override;

  StunAddressFamily family() const {
    switch (address_.family()) {
      case IpFamily::kV4:
        return STUN_ADDRESS_IPV4;
      case IpFamily::kV6:
        return STUN_ADDRESS_IPV6;
      default:
        return STUN_ADDRESS_UNDEF;
    }
  }

  const SocketAddress& GetAddress() const { return address_; }
  const IpAddress& ipaddr() const { return address_.ipaddr(); }
  uint16_t port() const { return address_.port(); }

  void SetAddress(const SocketAddress& addr) {
    address_ = addr;
    EnsureAddressLength();
  }
  void SetIP(const IpAddress& ip) {
    address_.SetIp(ip);
    EnsureAddressLength();
  }
  void SetPort(uint16_t port) { address_.SetPort(port); }

  bool Read(ByteBufferReader* buf) override;
  bool Write(ByteBufferWriter* buf) const override;

};

// The send callback must not add or remove requests (it runs inside a send).
class StunRequestManager {
 public:
  using SendPacketFn = std::function<void(Timestamp now, std::span<const uint8_t>, StunRequest*)>;

  explicit StunRequestManager(SendPacketFn send_packet);
  ~StunRequestManager();
  StunRequestManager(const StunRequestManager&) = delete;
  StunRequestManager& operator=(const StunRequestManager&) = delete;

  // Starts `request`: sent at `now + delay` (now if zero), then resent until a
  // response or the timeout. Returns false, and drops the request, when
  // transaction ids would be predictable (see the top of the file).
  bool Send(Timestamp now, std::unique_ptr<StunRequest> request, TimeDelta delay = TimeDelta::Zero());

  // Sends, resends and times out what is due by `now`.
  void Process(Timestamp now);
  // When Process next has something to do; PlusInfinity when idle.
  Timestamp NextProcessTime() const;

  // Sends every request of `msg_type` (or all) again now and restarts its
  // schedule.
  void FlushForTest(Timestamp now, int msg_type);
  bool HasRequestForTest(int msg_type) const;

  // Drops every request without calling it back.
  void Clear();

  // Matches a response to its request and calls the request back. True if it
  // was a response to one of ours that was accepted.
  bool CheckResponse(Timestamp now, StunMessage* msg);
  // The same from the bytes: looks the transaction id up first, then parses.
  bool CheckResponse(Timestamp now, std::span<const uint8_t> payload);

  bool empty() const { return requests_.empty(); }

  // Allows the fixed-seed transaction ids of sm/p2p/stun.h when no crypto is
  // installed. Tests only.
  void set_allow_predictable_ids_for_testing(bool allow) { allow_predictable_ids_ = allow; }

};

class StunRequest {
 public:
  // A binding-less request with an invalid type and a generated id, as
  // libwebrtc's first constructor; subclasses fill mutable_msg().
  explicit StunRequest(StunRequestManager& manager);
  StunRequest(StunRequestManager& manager, std::unique_ptr<StunMessage> message);
  virtual ~StunRequest();
  StunRequest(const StunRequest&) = delete;
  StunRequest& operator=(const StunRequest&) = delete;

  StunRequestManager* manager() { return &manager_; }
  const std::string& id() const { return msg_->transaction_id(); }
  uint32_t reduced_transaction_id() const { return msg_->reduced_transaction_id(); }
  int type() const { return msg_->type(); }
  const StunMessage* msg() const { return msg_.get(); }
  // Time since the latest send.
  TimeDelta Elapsed(Timestamp now) const { return now - tstamp_; }
  void SetAuthenticationRequired(bool val) { authentication_required_ = val; }
  bool AuthenticationRequired() const { return authentication_required_; }

 protected:
  friend class StunRequestManager;
  StunMessage* mutable_msg() { return msg_.get(); }

  virtual void OnResponse(Timestamp /*now*/, StunMessage* /*response*/) {}
  virtual void OnErrorResponse(Timestamp /*now*/, StunMessage* /*response*/) {}
  virtual void OnTimeout(Timestamp /*now*/) {}
  // Called after each send; the base counts sends and decides the timeout.
  virtual void OnSent(Timestamp now);
  // Delay to the next send: 0 before the first, then the backoff.
  virtual int resend_delay() const;
  void set_timed_out() { timeout_ = true; }

};

class StunServer {

    socket_->RegisterReceivedPacketCallback(
        [this](p2p::AsyncPacketSocket*, const p2p::ReceivedPacket& p) { OnPacket(p); });

  StunServer(const StunServer&) = delete;
  StunServer& operator=(const StunServer&) = delete;

  p2p::SocketAddress address() const { return socket_->GetLocalAddress(); }
  int binding_requests() const { return binding_requests_; }

  // GetStunBindResponse: the mapped address of `remote` for `request`.
  static void GetStunBindResponse(const p2p::StunMessage& request, const p2p::SocketAddress& remote,
                                  p2p::StunMessage* response) {
    std::unique_ptr<p2p::StunAddressAttribute> mapped;
    if (request.IsLegacy()) {
      mapped = p2p::StunAttribute::CreateAddress(p2p::STUN_ATTR_MAPPED_ADDRESS);
    } else {
      mapped = p2p::StunAttribute::CreateXorAddress(p2p::STUN_ATTR_XOR_MAPPED_ADDRESS);
    }
    mapped->SetAddress(remote);
    response->AddAttribute(std::move(mapped));
  }

};

}  // namespace sm::sim

**End-to-end test** (sender -> simulated network -> receiver, `tests/e2e/`):


Every message type and attribute of the unit tests is built, written and read back. RFC 5769's sample requests and responses are checked with the integrity and fingerprint code of the TLS backend. `StunRequestManager` retransmits a request on libwebrtc's schedule and drops late responses.
