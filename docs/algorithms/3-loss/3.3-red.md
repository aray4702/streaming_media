# 3.3 RED audio redundancy (RFC 2198)

Section 3, *Packet loss*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- Lost audio frames -> RED redundancy for audio

## The issue

Audio packets are small (20 ms, 20-100 bytes) and sent continuously. A lost packet is a 20 ms hole that the listener hears as a click or a dropout, and retransmission is usually too slow for audio's tight playout delay. Packet headers (IP/UDP/RTP, about 40 bytes) often outweigh the payload. Repeating the previous frame inside the next packet therefore adds less than one extra packet's worth of bitrate and repairs isolated losses with only one frame of extra delay. The receiver must then recognise, by timestamp, which frames it already has and use each frame exactly once.

## Design

(primary) audio frame plus copies of the previous `distance` frames, so a single (or burst up to `distance`) loss is repaired by the next packet at the cost of extra bitrate and no extra delay beyond one frame.

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#3-packet-loss) for the differences from libwebrtc. Residual loss is roughly p^(d+1) for random loss, at a bitrate cost of about d x the primary payload. Redundant blocks are bounded to the 10-bit length and 14-bit timestamp offset of the RFC 2198 header.

## Implementation skeleton

Files: [include/sm/loss/red.h](../../../include/sm/loss/red.h), [src/loss/red.cc](../../../src/loss/red.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::loss {

struct RedBlock {
  uint8_t payload_type = 0;
  uint32_t timestamp = 0;
  std::vector<uint8_t> payload;
  bool primary = false;
};

// Parses a RED payload. `rtp_timestamp` is the RTP timestamp of the carrying
// packet (= timestamp of the primary block). Blocks are returned oldest first.
std::optional<std::vector<RedBlock>> ParseRed(std::span<const uint8_t> payload, uint32_t rtp_timestamp);

struct RedStats {
  uint64_t packets = 0;
  int64_t primary_bytes = 0;
  int64_t redundant_bytes = 0;
  uint64_t frames_out = 0;          // Receiver: unique frames delivered.
  uint64_t recovered_frames = 0;    // Receiver: delivered from a redundant block.
  uint64_t parse_errors = 0;
};

class RedEncoder : public MetricsSource {
 public:
  // distance: number of previous frames to repeat (1-3 typical).
  explicit RedEncoder(int distance = 1, size_t max_redundant_bytes = 1023);
  std::vector<uint8_t> Encode(uint8_t payload_type, uint32_t timestamp, std::span<const uint8_t> frame);
  const RedStats& stats() const { return stats_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

// Turns a stream of RED packets back into unique frames ordered as they
// become available, filling holes from redundancy.
class RedReceiver : public MetricsSource {
 public:
  explicit RedReceiver(size_t memory = 64) : memory_(memory) {}
  std::vector<RedBlock> OnPacket(std::span<const uint8_t> payload, uint32_t rtp_timestamp);
  const RedStats& stats() const { return stats_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::loss
```
