# 3.6 Temporal scalability (L1T2/L1T3)

Section 3, *Packet loss*, of [Problems WebRTC solves](../../02-webrtc-problems-solved.md). Problems addressed:

- A single loss breaking every later frame -> Temporal layers / SVC: dependent frames can be dropped safely

## The issue

With a simple reference chain (each frame references the previous one) any single lost frame breaks all following frames until a keyframe. This is fragile on lossy links, and it is wasteful in group calls: an SFU cannot reduce the frame rate for a slow receiver, because dropping any frame breaks the chain for everyone downstream.

Temporal scalability arranges references in layers so some frames are never referenced by others. Those frames can be lost or dropped without consequence. Switching a receiver up to a higher layer is only safe at frames that do not depend on frames the receiver never got.

## Design

The scheduler assigns each frame a temporal layer id (tid) and the frames it may reference, so frames of a higher layer are never referenced by a lower or same layer. Losing or dropping a T1/T2 frame therefore never breaks decoding of later T0 frames; an SFU can also drop upper layers to halve or quarter the frame rate for a slow receiver.

```
  L1T2 (period 2): T0 T1 T0 T1 ...        T1 refs the last T0
  L1T3 (period 4): T0 T2 T1 T2 T0 ...     T1 refs T0, T2 refs T0 or T1
```

See the [libwebrtc parity inventory](../../design/libwebrtc-parity.md#3-packet-loss) for the differences from libwebrtc. Bitrate split follows libvpx defaults (40/20/40% for L1T3). Layer-sync frames (that depend only on T0) are where a receiver may switch up.

## Implementation skeleton

Files: [include/sm/loss/temporal_layers.h](../../../include/sm/loss/temporal_layers.h), [src/loss/temporal_layers.cc](../../../src/loss/temporal_layers.cc).

Public API (generated from the header; private members omitted):

```cpp
namespace sm::loss {

struct LayerFrame {
  int temporal_id = 0;
  bool keyframe = false;
  bool layer_sync = false;  // Depends only on T0: safe point to switch up.
  FrameInfo info;           // frame_id + references.
};

class TemporalLayerScheduler {
 public:
  explicit TemporalLayerScheduler(int num_layers);
  int num_layers() const { return layers_; }
  LayerFrame NextFrame(bool force_keyframe = false);
  // Share of total bitrate per layer, cumulative (e.g. {0.6, 1.0} for L1T2,
  // {0.4, 0.6, 1.0} for L1T3, as in libvpx defaults).
  static std::vector<double> CumulativeBitrateShare(int num_layers);
  // Frame-rate fraction available when forwarding layers <= tid.
  static double FramerateFraction(int num_layers, int max_tid);

};

struct LayerFilterStats {
  std::array<uint64_t, 3> forwarded{};
  std::array<uint64_t, 3> dropped{};
  uint64_t switches = 0;
};

// Selective forwarding: forwards frames with tid <= the target, switching up
// only at layer-sync frames so the receiver never sees a frame whose
// references it did not get.
class TemporalLayerFilter : public MetricsSource {
 public:
  void SetTargetLayer(int tid) { target_ = tid; }
  bool ShouldForward(const LayerFrame& f);
  int current_layer() const { return current_; }
  const LayerFilterStats& stats() const { return stats_; }
  void ExportMetrics(MetricsWriter& w) const override;

};

}  // namespace sm::loss
```
